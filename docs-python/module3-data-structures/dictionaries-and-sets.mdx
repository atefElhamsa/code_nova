# 3.2 القواميس (Dictionaries) والمجموعات (Sets)

بعد أن تعلمنا تخزين البيانات بالترتيب (Lists)، سنتعلم الآن تخزين البيانات عن طريق **الربط (Mapping)** باستخدام القواميس، أو تخزين البيانات **الفريدة فقط** باستخدام المجموعات. هذه الهياكل تجعل عمليات البحث سريعة جداً.

---

## 1. القواميس (Dictionaries - `dict`)

القاموس في بايثون يشبه القاموس الحقيقي: يحتوي على "كلمة" (Key) و "معناها" (Value).
تستخدم القواميس لتخزين البيانات على شكل أزواج (Key-Value)، حيث **يجب أن يكون الـ Key فريداً (لا يتكرر)**. وتكتب داخل أقواس معقوفة `{}`.

```python
# تعريف قاموس لبيانات مستخدم
student = {
    "name": "Ali",
    "age": 22,
    "major": "Computer Science",
    "is_active": True
}

# 1. الوصول للقيمة عن طريق الـ Key
print(student["name"]) # Ali

# 2. تعديل قيمة موجودة
student["age"] = 23

# 3. إضافة زوج جديد (Key-Value)
student["gpa"] = 3.8

print(student)
```

### ماذا لو استخدمنا مفتاحاً غير موجود؟
إذا حاولت طباعة `student["phone"]` ستحصل على خطأ قاسي (KeyError) يوقف البرنامج.
الطريقة الآمنة والمفضلة هي استخدام دالة `.get()`، والتي تُرجع `None` إذا لم تجد المفتاح، أو يمكنك تحديد قيمة افتراضية.

```python
# آمن: سيرجع "Not Found" بدلاً من الخطأ
phone = student.get("phone", "Not Found")
print(phone)
```

### المرور على القاموس (Looping)

```python
# المرور على المفاتيح (الافتراضي)
for key in student:
    print(key)

# المرور على الأزواج معاً باستخدام .items()
for key, value in student.items():
    print(f"{key}: {value}")
```

## 2. المجموعات (Sets)

الـ `Set` هي مجموعة من العناصر التي تتميز بصفتين:
1. **لا تسمح بالتكرار (Unique Elements):** أي عنصر مكرر يتم تجاهله تلقائياً.
2. **غير مرتبة (Unordered):** لا يمكنك استخدام الفهرس (مثل `my_set[0]`) لأن البيانات مخزنة عشوائياً في الذاكرة لتسهيل البحث السريع.

تُكتب أيضاً بـ `{}` ولكنها مجرد قيم فردية وليست أزواج كالقواميس.

```python
# إنشاء مجموعة
fruits = {"Apple", "Banana", "Orange"}

# إضافة عنصر
fruits.add("Mango")

# محاولة إضافة عنصر موجود (سيتم تجاهله)
fruits.add("Apple") 

print(fruits) # ترتيب الطباعة قد يختلف كل مرة!
```

### سحر المجموعات: تحويل الـ Lists لإزالة التكرار
إذا كان لديك قائمة مليئة بالأرقام المكررة وتريد تصفيتها، الحل الأمثل هو تحويلها لـ Set ثم إعادتها لـ List:

```python
numbers_list = [1, 2, 2, 3, 4, 4, 5, 1]
unique_numbers = list(set(numbers_list))

print(unique_numbers) # [1, 2, 3, 4, 5]
```

### عمليات المجموعات الرياضية (Set Operations)
بايثون تدعم عمليات الرياضيات الخاصة بالمجموعات مثل التقاطع والاتحاد!

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

# التقاطع (العناصر المشتركة)
print(a.intersection(b)) # {3, 4} أو a & b

# الاتحاد (كل العناصر بدون تكرار)
print(a.union(b))        # {1, 2, 3, 4, 5, 6} أو a | b
```

## ⚡ Performance Notes

:::tip القوة الغاشمة لـ Hash Tables
القواميس والمجموعات (`dict` و `set`) مبنية باستخدام هيكل بيانات يسمى (Hash Tables). هذا يعني أن عملية البحث `if item in my_set:` تأخذ وقتاً ثابتاً $O(1)$ مهما كان حجم البيانات. 
إذا كان لديك 10 مليون رقم، وتريد التحقق هل الرقم 5 موجود أم لا، فإن البحث في `List` قد يستغرق ثواني، بينما البحث في `Set` أو `Dict` سيحدث في أجزاء من الملي ثانية. **دائماً استخدم Sets للبحث!**
:::

## ⚠️ الأخطاء الشائعة (Common Mistakes)

```python
# ❌ 1 - استخدام مفتاح قابل للتعديل (Mutable) في القاموس
my_dict = {
    # ["John", "Doe"]: 25 
    # 💥 خطأ: TypeError: unhashable type: 'list'
}
# ✅ الصحيح: استخدم Tuple بدلاً من List كمفتاح لأنه غير قابل للتعديل (Immutable)
my_dict = {
    ("John", "Doe"): 25 
}

# ❌ 2 - استخدام {} لإنشاء مجموعة فارغة
my_set = {}
print(type(my_set)) # 💥 سيطبع <class 'dict'>! بايثون تعتبر الأقواس الفارغة قاموساً وليس مجموعة.
# ✅ الصحيح:
real_empty_set = set()
```

## Interview Questions & Answers

<details>
<summary><strong>Q1: لماذا البحث عن عنصر داخل `Set` أسرع بكثير من البحث داخل `List`؟</strong></summary>

الـ List تستخدم مصفوفة خطية (Linear Array)، فإذا بحثنا عن عنصر قد نضطر للمرور على جميع العناصر (O(n)).
أما الـ Set في بايثون فهي مبنية باستخدام جداول التجزئة (Hash Tables)، مما يجعل عملية التحقق من وجود عنصر شبه فورية وتأخذ وقتاً ثابتاً (O(1)) مهما كبر حجم المجموعة.
</details>

<details>
<summary><strong>Q2: هل يمكن استخدام List لتكون الـ Key في قاموس Dictionary؟</strong></summary>

**لا يمكن.** القواميس في بايثون تشترط أن يكون المفتاح (Key) من نوع بيانات غير قابل للتعديل (Immutable) لكي يستطيع الـ Hash Table العمل بشكل صحيح. يمكنك استخدام الـ `String`، `Integer`، و الـ `Tuple` كمفاتيح، لكن الـ `List` والـ `Set` ممنوعة.
</details>

<SummaryBox title="📌 Lesson Summary">

- **`Dictionary {}`**: لتخزين البيانات المترابطة (مفتاح وقيمة). المفاتيح فريدة.
- استخدم `dict.get(key)` لتجنب الأخطاء عند البحث عن مفتاح غير موجود.
- **`Set {}`**: تخزن قيماً فريدة وغير مرتبة. مثالية للبحث السريع وعمليات التقاطع وإزالة التكرارات.
- يمكن تحويل الهياكل بسهولة: `list(set(my_list))`.

</SummaryBox>
