# 1.1 مقدمة عن بايثون وإعداد بيئة العمل

مرحباً بك في دورة بايثون (Python)! لغة البرمجة التي غيرت العالم ببساطتها وقوتها، وهي لغة المستقبل المتربعة على عرش الذكاء الاصطناعي وتحليل البيانات.

---

## الأهداف التعليمية

1. ما هي بايثون ولماذا هي اللغة الأكثر شعبية؟
2. تثبيت بايثون على جهازك (Windows/Mac/Linux).
3. إعداد محرر الأكواد (VS Code).
4. كتابة أول برنامج بلغة بايثون (Hello World).

---

## 1. ما هي بايثون؟ ولماذا نتعلمها؟

بايثون هي لغة برمجة عالية المستوى (High-level)، صممها Guido van Rossum عام 1991. الفلسفة الأساسية لها هي: **الكود يجب أن يكون سهل القراءة وممتعاً في الكتابة.**

**مميزات بايثون:**
- **سهولة التعلم:** تشبه اللغة الإنجليزية البسيطة، ولا تحتوي على الأقواس المعقدة الموجودة في اللغات الأخرى (مثل C++ أو Java).
- **لغة مفسرة (Interpreted):** لا تحتاج إلى (Compile)؛ الكود يُقرأ ويُنفذ سطراً بسطر مما يسهل اكتشاف الأخطاء.
- **مجالات واسعة (Versatility):**
  - الذكاء الاصطناعي وتعلم الآلة (AI & Machine Learning).
  - تطوير الويب (Django & Flask).
  - تحليل البيانات (Pandas & NumPy).
  - الأتمتة (Automation) والسكريبتات السريعة.

---

## 2. إعداد بيئة العمل (Setup)

لكي يقرأ جهازك كود بايثون وينفذه، نحتاج إلى تثبيت "مُفسر بايثون" (Python Interpreter) ومحرر أكواد.

### الخطوة الأولى: تثبيت بايثون
1. اذهب إلى الموقع الرسمي [Python.org](https://www.python.org/downloads/).
2. حمل أحدث إصدار (مثل Python 3.12).
3. ⚠️ **خطوة حرجة جداً لمستخدمي ويندوز:** عند بدء التثبيت، تأكد من وضع علامة صح على مربع **"Add Python to PATH"** أسفل النافذة، وإلا لن يعمل بايثون من الـ Terminal.
4. أكمل التثبيت بضغط (Install Now).

### الخطوة الثانية: التأكد من التثبيت
افتح موجه الأوامر (Command Prompt في ويندوز) أو (Terminal في ماك/لينكس) واكتب:
```bash
python --version
# أو
python3 --version
```
إذا ظهر لك رقم الإصدار (مثلاً Python 3.12.0)، فالتثبيت ناجح!

### الخطوة الثالثة: محرر الأكواد (VS Code)
1. حمل وثبت [Visual Studio Code](https://code.visualstudio.com/).
2. افتح البرنامج، اذهب للـ Extensions وابحث عن **Python** (الرسمية من Microsoft) وقم بتثبيتها.

> ✅ **نصيحة للمبتدئين:** إذا واجهت مشاكل في التثبيت، يمكنك كتابة وتجربة أكوادك مباشرة على متصفحك عبر مواقع مثل [Replit](https://replit.com/languages/python3) أو [Programiz](https://www.programiz.com/python-programming/online-compiler).

## 3. أول برنامج بايثون (Hello World)

قم بإنشاء ملف جديد في VS Code وسمّه `main.py` (امتداد بايثون هو `.py`).

اكتب السطر التالي فقط:
```python
print("Hello, CodeNova!")
```

### كيف نشغله؟
في VS Code، يمكنك الضغط على زر التشغيل ▷ أعلى يمين الشاشة، أو فتح الـ Terminal الخاص به وكتابة:
```bash
python main.py
```
**النتيجة ستكون:** `Hello, CodeNova!`

**لماذا هو بسيط هكذا؟**
في لغات مثل C++ نحتاج إلى استدعاء مكتبات `include` وتعريف دالة `main` وأقواس `{}`. في بايثون، الأمر مباشر: اكتب ما تريده وسينفذه المفسر فوراً!

##  أسئلة المقابلات الشخصية (Interview Questions)

<details>
<summary><strong>Q1: ما الفرق بين Compiled Language (مثل C++) و Interpreted Language (مثل Python)؟</strong></summary>

- **Compiled (مترجمة):** يتم تحويل الكود كاملاً مرة واحدة إلى لغة الآلة (1 و 0) قبل التشغيل. مما يجعلها **أسرع جداً** في التشغيل ولكن أبطأ في التطوير واكتشاف الأخطاء.
- **Interpreted (مفسرة):** المفسر يقرأ الكود وينفذه سطراً بسطر في وقت التشغيل (Runtime). هذا يجعل بايثون أبطأ في الأداء، ولكنها أسهل وأسرع بكثير في التطوير والـ Debugging.
</details>

<details>
<summary><strong>Q2: ما المقصود بـ "Add Python to PATH" ولماذا هي مهمة؟</strong></summary>

نظام التشغيل (ويندوز) لا يعرف أين تم تثبيت برامجك. الـ PATH هو متغير بيئة (Environment Variable) يحتوي على مسارات البرامج الهامة. عند إضافة بايثون للـ PATH، يمكنك فتح أي نافذة موجه أوامر من أي مكان في جهازك وكتابة `python` وسيفهم النظام أنك تقصد مفسر بايثون. بدونها ستحصل على خطأ "python is not recognized".
</details>

<SummaryBox title="📌 Lesson Summary">

- بايثون لغة **مفسرة (Interpreted)**، عالية المستوى، وسهلة القراءة.
- يجب تثبيت مُفسر بايثون أولاً، ولا تنس وضع علامة **Add to PATH** في ويندوز.

- لا توجد فاصلة منقوطة `;` أو أقواس معقدة `{}` في بايثون.
