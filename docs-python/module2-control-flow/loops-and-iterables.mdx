# 2.2 الحلقات التكرارية (Loops) والـ Iterables

تسمح لنا الحلقات التكرارية بتنفيذ نفس مجموعة الأوامر لعدد محدد من المرات، أو طالما أن شرطاً معيناً لا يزال صحيحاً.
في بايثون لدينا نوعان أساسيان من الحلقات: الـ `for` (والتي تختلف جذرياً عن اللغات الأخرى) والـ `while`.

---

## 1. حلقة `while`

تستخدم الـ `while` عندما **لا نعرف** عدد المرات المحددة التي نحتاجها للتكرار، بل نعتمد على "شرط". طالما أن الشرط صحيح (True)، استمر في الحلقة.

```python
counter = 1

while counter <= 5:
    print(f"Counter is at {counter}")
    counter += 1  # تعني counter = counter + 1 (مهم جداً وإلا سنتورط في حلقة لا نهائية!)
```

---

## 2. حلقة `for` السحرية في بايثون

إذا كنت قادماً من لغة C++ أو جافا، فانسَ صيغة `for(int i=0; i<5; i++)`.
حلقة `for` في بايثون مصممة لكي **تمر (Iterate) على تسلسل من العناصر (Iterable)**؛ مثل النص، القائمة، أو مجموعة من الأرقام.

### أ. المرور على نص (String)
```python
word = "Python"
for letter in word:
    print(letter) 
# سيطبع كل حرف في سطر منفصل
```

### ب. استخدام دالة `range()`
إذا كنت تريد حلقة تتكرر لعدد محدد من المرات (مثلاً 5 مرات)، نستخدم دالة `range()`.
`range(5)` تولد أرقاماً من `0` إلى `4`.

```python
# سيطبع 0, 1, 2, 3, 4
for i in range(5):
    print(i)

# يمكنك تحديد البداية والنهاية
# سيطبع 10, 11, 12, 13, 14
for i in range(10, 15):
    print(i)

# يمكنك أيضاً تحديد مقدار القفزة (Step)
# سيطبع 0, 2, 4, 6, 8 (أرقام زوجية فقط)
for i in range(0, 10, 2):
    print(i)
```

### ج. الحلقات المتداخلة (Nested Loops)

كما في الشروط المتداخلة، يمكنك كتابة حلقة تكرارية داخل أخرى. في بايثون، **المسافة البادئة (Indentation)** هي التي تحدد أين تبدأ الحلقة الداخلية وأين تنتهي. مع كل دورة للحلقة الخارجية، يتم تنفيذ الحلقة الداخلية بالكامل.

```python
# مثال: طباعة جدول ضرب 1 و 2
for i in range(1, 3):       # الحلقة الخارجية
    print(f"Table of {i}")
    
    for j in range(1, 4):   # الحلقة الداخلية
        print(f"  {i} x {j} = {i * j}")

# النتيجة:
# Table of 1
#   1 x 1 = 1
#   1 x 2 = 2
#   1 x 3 = 3
# Table of 2
#   2 x 1 = 2
#   2 x 2 = 4
#   2 x 3 = 6
```
> ⚠️ **تنبيه:** الحلقات المتداخلة قد تسبب بطء في الأداء إذا كانت البيانات كبيرة جداً (لأن الأداء يصبح $O(N^2)$). استخدمها فقط عند الضرورة.

---

## 3. التحكم في الحلقة: `break` و `continue`

- **`break`**: تكسر الحلقة وتخرجك منها فوراً، مهما كانت الشروط الأخرى.
- **`continue`**: تتجاهل ما تبقى من الدورة الحالية فقط، وتنتقل للدورة التي تليها مباشرة.

```python
print("--- Using break ---")
for i in range(1, 10):
    if i == 5:
        break # سيتوقف البرنامج تماماً عند الرقم 5
    print(i)
# 1 2 3 4

print("--- Using continue ---")
for i in range(1, 6):
    if i == 3:
        continue # سيتجاهل الرقم 3 ولن يطبعه
    print(i)
# 1 2 4 5
```

---

## 4. الميزة المخفية: `for - else`

من الميزات الغريبة والفريدة في بايثون، يمكنك إضافة `else` في نهاية حلقة `for` أو `while`!
البلوك الخاص بالـ `else` يتم تنفيذه **فقط** إذا انتهت الحلقة بشكلها الطبيعي (أي لم يتم كسرها بواسطة `break`).

تفيد جداً في خوارزميات "البحث".

```python
numbers = [1, 3, 5, 7]
search_for = 4

for num in numbers:
    if num == search_for:
        print("Found it!")
        break
else:
    # هذا السطر سينفذ فقط إذا بحثنا في كل الأرقام ولم نجد الرقم (ولم يحدث break)
    print("Not found in the list.")
```

## ⚡ Performance Notes

:::tip حلقة `for` أسرع من `while`
في بايثون، حلقة `for` أسرع بكثير من حلقة `while` عند المرور على البيانات. والسبب هو أن `for` تم برمجتها وتحسينها بداخل لغة الـ C (لغة بايثون مبنية على C)، بينما `while` تتطلب تقييم الشرط في كل دورة ببطء بايثون المعتاد.
أيضاً، الدوال الجاهزة مثل `sum()` أو استخدام (List Comprehensions) التي سنتعلمها لاحقاً، أسرع مرات عديدة من كتابة حلقة `for` يدوية.
:::

## ⚠️ الأخطاء الشائعة (Common Mistakes)

```python
# ❌ 1 - نسيان زيادة العداد في حلقة while
count = 0
while count < 5:
    print("Hello")
    # 💥 كارثة: لم نقم بزيادة count، هذه حلقة لا نهائية (Infinite Loop) وسيتجمد البرنامج!
    # ✅ الصحيح: count += 1

# ❌ 2 - التعديل على القائمة أثناء المرور عليها بحلقة for
names = ["Ahmed", "Sara", "Ali"]
for name in names:
    if name == "Ahmed":
        names.remove(name) 
        # 💥 خطأ منطقي خفي: إزالة عنصر من القائمة أثناء الـ Loop يغير ترتيب العناصر المتبقية، مما يجعل الـ Loop تتخطى عناصر ولن تعمل بشكل صحيح.
        # ✅ الصحيح: لا تعدل القائمة أبداً وأنت تمر عليها، بل أنشئ قائمة جديدة وضع فيها ما تريد.
```

## Interview Questions & Answers

<details>
<summary><strong>Q1: هل يمكن إنشاء حلقة لا نهائية (Infinite Loop) باستخدام `for` في بايثون؟</strong></summary>

في العادة، حلقة `for` في بايثون تمر على تسلسل (مثل Range أو List) وعندما ينتهي التسلسل تتوقف، لذلك من الصعب جداً إنشاء حلقة لا نهائية بها عن طريق الخطأ (عكس اللغات الأخرى).
لإنشاء حلقة لا نهائية نستخدم دائماً الـ `while True:`، مع وضع شرط `break` بداخلها لإيقافها متى أردنا.
</details>

<details>
<summary><strong>Q2: ماذا ترجع دالة `range()`؟ هل هي مصفوفة (List)؟</strong></summary>

لا. في بايثون 3، دالة `range()` ترجع كائناً من نوع "Range Object". وهو كائن (Lazy)، يعني لا يقوم بتوليد الأرقام كلها وتخزينها في الذاكرة (مما يستهلك الـ RAM لو كتبنا `range(1000000)`)، بل يقوم بتوليد الرقم التالي فقط عند الحاجة إليه أثناء الـ Loop.
إذا أردت تحويله إلى قائمة حقيقية يمكنك استخدام `list(range(5))` فتصبح `[0, 1, 2, 3, 4]`.
</details>

باستخدام `while`، اكتب برنامجاً يحدد رقماً سرياً (مثلاً `secret = 7`).

<details>
<summary><strong>💡 اضغط هنا لرؤية الحل النموذجي</strong></summary>

```python
secret_number = 7

print("Welcome to the Guessing Game!")

while True: # حلقة لا نهائية حتى ينجح
    guess = int(input("Guess the secret number: "))
    
    if guess == secret_number:
        print("Congratulations! You won!")
        break # كسر الحلقة والانتهاء
    else:
        print("Wrong! Try again.")
```

<SummaryBox title="📌 Lesson Summary">

- الـ **`while` loop** تستمر طالما أن الشرط True.
- الـ **`for` loop** تستخدم للمرور على العناصر أو باستخدام دالة `range()`.
- دالة **`range(start, stop, step)`** مثالية لتحديد عدد معين من التكرارات.
- **`break`** تُنهي الحلقة، و **`continue`** تتجاهل الدورة الحالية.
- يمكن استخدام **`else`** مع الحلقات للتأكد من أنها انتهت بدون `break`.

</SummaryBox>
