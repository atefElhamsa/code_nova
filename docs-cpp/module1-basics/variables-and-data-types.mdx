# 1.2 المتغيرات وأنواع البيانات

البيانات هي العصب الرئيسي لأي برنامج. في C++، تحتاج إلى إخبار الحاسوب بـ **نوع** البيانات التي تود تخزينها (Type) قبل استخدامها.

---

## الأهداف التعليمية

1. فهم طريقة تعريف المتغيرات (Variables).
2. التعرف على الأنواع الأساسية: `int`, `float`, `double`, `char`, `bool`, `string`.
3. فهم الثوابت باستخدام `const`.
4. التعرف على قواعد تسمية المتغيرات.

---

## 1. ما هو المتغير (Variable)؟

المتغير ببساطة هو مساحة يتم حجزها في الذاكرة (RAM) لتخزين قيمة معينة. لتخزين أي شيء، يجب أن نحدد النوع، الاسم، ثم القيمة.

**الصيغة العامة:**
```cpp
type variableName = value;
```

---

## 2. أنواع البيانات الأساسية (Data Types)

C++ لغة **Strongly Typed** (يجب تحديد النوع صراحةً). إليك الأنواع الأكثر استخداماً:

| النوع | الوصف | مثال | الحجم التقريبي |
|---|---|---|---|
| `int` | أعداد صحيحة (بدون كسور) | `10`, `-5` | 4 bytes |
| `float` | أعداد عشرية (دقة عادية) | `3.14f`, `5.99f` | 4 bytes |
| `double`| أعداد عشرية (دقة عالية) | `19.99`, `-0.01` | 8 bytes |
| `char` | حرف واحد (يُكتب بين `' '`) | `'A'`, `'z'` | 1 byte |
| `bool` | قيمة منطقية (صح/خطأ) | `true`, `false` | 1 byte |
| `string`| نصوص (تُكتب بين `" "`) | `"CodeNova"` | متغير |

### أمثلة عملية:

```cpp
#include <iostream>
#include <string> // ضروري للتعامل مع النصوص

using namespace std;

int main() {
    int age = 25;
    double price = 99.99;
    char grade = 'A';
    bool isPassed = true;
    string name = "Omar";

    // الطباعة
    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Grade: " << grade << endl;

    return 0;
}
```

> ⚠️ **ملاحظة:** للتعامل مع `string` في C++، يجب إضافة المكتبة الخاصة بها `#include <string>` في أعلى الملف.

---

## 3. الفرق بين `float` و `double`

كلاهما يخزن أرقاماً بكسور، ولكن `double` أدق ويستطيع تخزين أرقام بعد الفاصلة العشرية تصل إلى 15 رقماً، بينما `float` يدعم حوالي 7 أرقام.
في C++، تعتبر أي قيمة عشرية تلقائياً من نوع `double`. وإذا أردت إجبارها لتكون `float` نضع الحرف `f`.

```cpp
float myFloat = 3.141592f;
double myDouble = 3.141592653589793;
```

---

## 4. الثوابت (Constants)

إذا كان لديك متغير لا تود أن تتغير قيمته أثناء تشغيل البرنامج (مثل قيمة الـ Pi، أو معدل الضريبة)، نستخدم كلمة `const`.

```cpp
const double PI = 3.14159;
// PI = 3.15; // ❌ خطأ: لا يمكن تغيير قيمة ثابت
```

---

## 5. قواعد تسمية المتغيرات النظيفة (Clean Code)

- يجب أن يبدأ بحرف أو شرطة سفلية `_`.
- لا يمكن أن يبدأ برقم (`1name` ❌).
- حساس لحالة الأحرف (case-sensitive)؛ يعني `Age` مختلف عن `age`.
- استخدم نمط الـ **camelCase** (الكلمة الأولى صغيرة والثانية تبدأ بحرف كبير) مثل: `studentAge` أو `totalPrice`.
- الأسماء يجب أن تكون وصفية (ابتعد عن الأسماء الغامضة مثل `x` و `y` إلا في حالات بسيطة جداً).

---

## ⚡ Performance Notes

:::tip اختيار النوع المناسب (Memory Optimization)
في الأجهزة الحديثة، قد لا يبدو حجم الذاكرة مشكلة. ولكن في برمجة الأنظمة المدمجة (Embedded Systems) أو الألعاب الكبيرة، اختيار النوع المناسب ضروري. إذا كنت تعرف أن الرقم لن يتجاوز 100 أبداً، لا تستخدم `long long` أو `double` لأنها تستهلك ضعف الذاكرة بدون فائدة.
:::

##  أسئلة المقابلات الشخصية (Interview Questions)

<details>
<summary><strong>Q1: ماذا يحدث إذا لم نقم بإعطاء قيمة مبدئية لمتغير في C++؟</strong></summary>

بخلاف بعض اللغات الحديثة، في C++ المتغيرات المحلية (داخل `main` مثلاً) التي لا تُعطى قيمة ابتدائية تحتوي على **قيمة عشوائية (Garbage Value)** موجودة مسبقاً في الذاكرة. لذلك يُنصح دائماً بإعطاء قيمة ابتدائية.
```cpp
int x; 
cout << x; // سيطبع رقماً عشوائياً!
```
</details>

<details>
<summary><strong>Q2: ما الفرق بين `'A'` و `"A"`؟</strong></summary>

- `'A'` المكتوب بعلامات تنصيص مفردة هو من نوع `char` ويحتل 1 بايت.
- `"A"` المكتوب بعلامات تنصيص مزدوجة هو من نوع `string` (نص) ويحتوي خلف الكواليس على الحرف 'A' بالإضافة لرمز إنهاء النص (`\0`) ويحتل مساحة أكبر.
</details>

## ⚠️ الأخطاء الشائعة (Common Mistakes)

```cpp
// ❌ 1 - عدم تهيئة المتغيرات (Uninitialized Variables)
int score;
cout << score; // 💥 خطأ: سيطبع قيمة عشوائية (Garbage Value) كانت موجودة في الذاكرة

// ✅ الصحيح:
int score = 0;

// ❌ 2 - استخدام كلمات محجوزة كأسماء متغيرات
// int return = 5; // 💥 خطأ: return كلمة محجوزة للنظام

// ❌ 3 - وضع فاصلة منقوطة زائدة أو نسيانها
int age = 20 // 💥 خطأ: نسيان الفاصلة المنقوطة
```

- نستخدم `int` للأرقام، `double` للأرقام العشرية، `char` للأحرف، و `string` للنصوص.
- يجب تضمين مكتبة `<string>` للتعامل المريح مع النصوص.
- الـ `const` تحمي المتغيرات من التعديل العرضي.
- لغة C++ حساسة لحالة الأحرف (Case-Sensitive).
