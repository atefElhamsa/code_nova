# 1.3 العمليات (Operators) والإدخال والإخراج (I/O)

في هذا الدرس سنتعلم كيف نجعل البرنامج يتفاعل مع المستخدم عبر أخذ البيانات منه (`cin`)، وكيف نقوم بإجراء العمليات الحسابية والمنطقية على هذه البيانات.

---

## 1. استقبال الإدخال من المستخدم (`cin`)

كما نستخدم `cout` (Character Output) للطباعة، نستخدم **`cin`** (Character Input) لأخذ البيانات من المستخدم.
نستخدم مع `cin` معامل الإدخال `>>` (Extraction Operator).

```cpp
#include <iostream>
#include <string>

using namespace std;

int main() {
    string name;
    int age;

    cout << "Enter your name: ";
    cin >> name; // استقبال النص

    cout << "Enter your age: ";
    cin >> age;  // استقبال الرقم

    cout << "Hello, " << name << "! You are " << age << " years old." << endl;

    return 0;
}
```

> ⚠️ **مشكلة الإدخال بالنصوص الطويلة:** `cin` تتوقف عن القراءة بمجرد رؤية "مسافة". إذا أدخل المستخدم "Ali Ahmed"، سيتم حفظ "Ali" فقط. لقراءة سطر كامل بمسافاته، نستخدم `getline(cin, name);`.

## 2. العمليات الحسابية (Arithmetic Operators)

تُستخدم للقيام بالعمليات الرياضية التقليدية:

| المعامل | الوصف | مثال (`a = 10, b = 3`) | النتيجة |
|---|---|---|---|
| `+` | جمع | `a + b` | `13` |
| `-` | طرح | `a - b` | `7` |
| `*` | ضرب | `a * b` | `30` |
| `/` | قسمة | `a / b` | `3` (قسمة أعداد صحيحة تهمل الكسر) |
| `%` | باقي القسمة | `a % b` | `1` (10 تقسيم 3 = 9 والباقي 1) |

### الانتباه للقسمة!
في C++، قسمة رقم صحيح (int) على رقم صحيح تعطي رقماً صحيحاً (يتم حذف الكسر). للحصول على نتيجة عشرية دقيقة، يجب أن يكون أحد الطرفين على الأقل `double` أو `float`.

```cpp
cout << 10 / 4 << endl;     // النتيجة: 2 (لأن كلاهما int)
cout << 10.0 / 4 << endl;   // النتيجة: 2.5 (لأن أحدهما double)
```

---

## 3. الزيادة والنقصان (Increment/Decrement)

اختصارات سريعة لزيادة أو تقليل قيمة المتغير بواحد:

- `++a` أو `a++`: يزيد القيمة بمقدار 1.
- `--a` أو `a--`: يقلل القيمة بمقدار 1.

```cpp
int x = 5;
x++; // أصبحت 6
x--; // عادت 5
```

---

## 4. العمليات المنطقية والمقارنة

نستخدمها لمقارنة القيم وسنعتمد عليها بشكل كبير في الدرس القادم (الشروط). نتيجتها دائماً تكون `bool` (أي `true` أو `false`).

| المعامل | الوصف | مثال |
|---|---|---|
| `==` | يساوي | `5 == 5` (true) |
| `!=` | لا يساوي | `5 != 3` (true) |
| `>` | أكبر من | `10 > 2` (true) |
| `<` | أصغر من | `4 < 1` (false) |
| `>=` | أكبر من أو يساوي | `5 >= 5` (true) |

### العمليات المنطقية (Logical Operators):
لربط أكثر من شرط معاً:
- `&&` (AND - و): يجب أن يكون كلا الشرطين صحيحاً.
- `||` (OR - أو): يكفي أن يكون أحدهما صحيحاً.
- `!` (NOT - النفي): يعكس الحالة (من صح لخطأ والعكس).

```cpp
bool isAdult = (age >= 18);
bool hasID = true;

bool canEnter = (isAdult && hasID); // هل هو بالغ ومعرف؟
```

## ⚡ Performance Notes

:::tip عمليات الزيادة (Pre vs Post Increment)
في حالة الـ Loops أو العمليات المتكررة آلاف المرات، استخدام `++i` (Pre-increment) أسرع وأكثر كفاءة بقليل من `i++` (Post-increment) لأنه لا يضطر لحفظ نسخة مؤقتة من القيمة القديمة في الذاكرة.
:::

##  أسئلة المقابلات الشخصية (Interview Questions)

<details>
<summary><strong>Q1: ما الفرق بين `a++` (Post-increment) و `++a` (Pre-increment)؟</strong></summary>

كلاهما يزيد القيمة بـ 1، ولكن الفرق يظهر عند استخدامهما في نفس السطر الذي تُطبع فيه القيمة.
- `a++` يعطي القيمة القديمة أولاً ثم يزيدها.
- `++a` يزيد القيمة أولاً ثم يعطي القيمة الجديدة.

```cpp
int a = 5;
cout << a++; // سيطبع 5، ثم تصبح a=6
int b = 5;
cout << ++b; // تصبح b=6، ثم يطبع 6
```
</details>

## ⚠️ الأخطاء الشائعة (Common Mistakes)

```cpp
// ❌ 1 - قسمة الأعداد الصحيحة (Integer Division)
int result = 10 / 4; 
cout << result; // 💥 سيطبع 2 فقط وليس 2.5 لأن القسمة تجاهلت الكسر!

// ✅ الصحيح (إجبار المترجم على حساب الكسر):
double correctResult = 10.0 / 4; 

// ❌ 2 - استخدام علامة يساوي واحدة للمقارنة
int x = 5;
if (x = 10) { // 💥 خطأ كارثي! هذا تعيين قيمة (Assignment) وسيُعتبر true دائماً!
    cout << "x is 10";
}

// ✅ الصحيح:
if (x == 10) { }
```

<SummaryBox title="📌 Lesson Summary">

- استخدم `cin` لأخذ مدخلات من المستخدم و `cout` للطباعة.
- انتبه عند استخدام `cin` مع نصوص بها مسافات، يفضل استخدام `getline()`.
- العمليات الحسابية في C++ قوية، ولكن احذر من قسمة الـ `int` على الـ `int` حيث تلغي الكسور.
- معاملات المقارنة `==`, `!=`, `<`, `>` تستخدم لمقارنة القيم وإرجاع قيم منطقية (`true` / `false`).

</SummaryBox>
