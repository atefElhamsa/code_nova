# 5.1 أساسيات المؤشرات (Pointers)

مرحباً بك في السلاح السري للغة C++! المؤشرات (Pointers) هي الميزة التي تجعل C++ قوية وسريعة جداً، وهي أيضاً أكثر ما يربك المبتدئين. دعنا نبسطها تماماً.

---

## 1. ما هي عناوين الذاكرة؟

الذاكرة العشوائية (RAM) في جهازك مقسمة إلى ملايين "الخانات"، كل خانة لها **عنوان (Address)** فريد مكتوب بالنظام الست عشري (Hexadecimal) مثل `0x7ffee9b`.
عندما نكتب `int score = 100;`، يحجز الكمبيوتر خانة في الذاكرة، يسميها `score`، ويضع فيها الرقم `100`.

لمعرفة "عنوان" هذا المتغير في الذاكرة، نستخدم المعامل `&` (Reference Operator).

```cpp
#include <iostream>
using namespace std;

int main() {
    int score = 100;
    
    cout << "Value: " << score << endl;       // 100
    cout << "Address: " << &score << endl;    // 0x7ffee9b... (رقم سيتغير عندك)
    
    return 0;
}
```

---

## 2. ما هو المؤشر (Pointer)؟

المؤشر ببساطة هو **متغير وظيفته الوحيدة هي تخزين "عنوان" لمتغير آخر في الذاكرة.**
لتعريف مؤشر، نستخدم علامة النجمة `*` بعد نوع البيانات.

```cpp
int score = 100;
int* ptr = &score; // ptr هو مؤشر يخزن عنوان score

cout << ptr << endl; // سيطبع عنوان score
```
*ملاحظة: يمكنك كتابة النجمة بجوار النوع `int* ptr` أو بجوار الاسم `int *ptr`، كلاهما صحيح.*

---

## 3. الـ Dereferencing (الوصول للقيمة عبر المؤشر)

الآن لدينا المؤشر الذي يعرف عنوان المتغير `score`. كيف يمكننا رؤية قيمة `score` (الـ 100) أو تعديلها من خلال هذا المؤشر؟
نستخدم علامة `*` مرة أخرى **قبل اسم المؤشر**، وتسمى هنا (Dereference Operator).

```cpp
int score = 100;
int* ptr = &score;

// طباعة القيمة من خلال المؤشر
cout << *ptr << endl; // 100

// تعديل القيمة من خلال المؤشر!
*ptr = 200;

// هل تغير score الأساسي؟
cout << score << endl; // نعم، أصبح 200!
```
**تخيلها هكذا:** 
المؤشر `ptr` هو خريطة تدلك على مكان الكنز (العنوان). 
الـ `*ptr` تعني "اذهب إلى المكان الذي تدل عليه الخريطة وافتح الصندوق لترى/تغير ما بداخله".

---

## 4. المؤشرات والمصفوفات (Pointers & Arrays)

هناك علاقة وثيقة جداً بين المصفوفات والمؤشرات في C++. في الواقع، **اسم المصفوفة بحد ذاته هو مؤشر يشير إلى العنصر الأول فيها**.

```cpp
int numbers[3] = {10, 20, 30};

// طباعة اسم المصفوفة فقط يعطينا عنوان العنصر الأول
cout << numbers << endl;      // 0x123...
cout << &numbers[0] << endl;  // 0x123... (نفس العنوان)

// باستخدام الـ Dereference
cout << *numbers << endl; // سيطبع 10 (العنصر الأول)

// Pointer Arithmetic (رياضيات المؤشرات)
cout << *(numbers + 1) << endl; // سيطبع 20 (العنصر الثاني)
```

## ⚡ Performance Notes

:::tip المؤشرات هي سر سرعة C++ (Zero-Overhead Abstraction)
المؤشرات تسمح للمبرمج بالوصول المباشر للذاكرة (Direct Memory Access). في اللغات الأخرى (مثل جافا أو بايثون) هناك طبقة حماية بين المبرمج والذاكرة (Virtual Machine) تبطئ التنفيذ. بينما في C++، باستخدامك للمؤشرات، أنت تتحدث مع المعالج والرام مباشرة، مما يسمح ببناء أنظمة فائقة السرعة تتفاعل مع العتاد (Hardware) بدون أي تأخير.
:::

## ⚠️ الأخطاء الشائعة (Common Mistakes)

```cpp
// ❌ 1 - المؤشر العشوائي (Wild Pointer)
int* ptr;
*ptr = 50; // 💥 خطأ كارثي: المؤشر لم يأخذ أي عنوان، فهو يؤشر لمكان عشوائي في الذاكرة. تغيير قيمته قد يدمر بيانات برامج أخرى (Segmentation Fault).

// ✅ الصحيح:
int x;
int* ptr = &x;
*ptr = 50;

// ❌ 2 - الخلط بين تغيير العنوان وتغيير القيمة
int a = 10;
int* p = &a;
p = 20; // 💥 خطأ: أنت تحاول تغيير "العنوان" الذي يشير إليه إلى العنوان 20.
*p = 20; // ✅ صحيح: أنت تغير "القيمة" الموجودة في العنوان إلى 20.
```

## Interview Questions & Answers

<details>
<summary><strong>Q1: ما هو الـ Null Pointer ولماذا هو مهم؟</strong></summary>

إذا قمت بتعريف مؤشر ولم تعطه عنواناً `int* ptr;`، فإنه سيشير إلى مكان عشوائي في الذاكرة (وهذا خطير جداً).
الـ Null Pointer هو مؤشر لا يشير إلى أي شيء، ونعطيه القيمة `nullptr` لتأمين الكود حتى نستخدمه لاحقاً.
```cpp
int* ptr = nullptr; // آمن وصحيح
```
*ملاحظة: في الكود القديم كانوا يستخدمون `NULL` أو `0`، لكن في C++ الحديثة (C++11 وما بعدها) نستخدم دائماً `nullptr`.*
</details>

<details>
<summary><strong>Q2: ما الفرق بين `&` و `*` في عالم المؤشرات؟</strong></summary>

- `&` (Reference): تُعطيك **العنوان** الذي يسكن فيه المتغير. (مثل أن تسأل أحدهم: أين تسكن؟)
- `*` (Dereference): تُعطيك **القيمة** الموجودة بداخل العنوان. (مثل أن تذهب للعنوان وتطرق الباب لترى من بالداخل).
</details>

<ExerciseBox title="🏋️ Exercise - اللعب بالمؤشرات">

1. عرّف متغيراً من نوع `double` يحمل قيمة `3.14` واسمه `pi`.
2. عرّف مؤشراً واسمه `piPtr` يمسك بعنوان المتغير `pi`.
3. اطبع قيمة `pi` الأصلية.
4. استخدم المؤشر `piPtr` (مع الـ Dereference `*`) لتغيير القيمة إلى `3.14159`.
5. اطبع قيمة `pi` الأصلية مرة أخرى لتتأكد من تغيرها.

</ExerciseBox>

<details>
<summary><strong>💡 اضغط هنا لرؤية الحل النموذجي</strong></summary>

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1
    double pi = 3.14;
    
    // 2
    double* piPtr = &pi;
    
    // 3
    cout << "Original pi: " << pi << endl;
    
    // 4. تغيير القيمة عن طريق المؤشر
    *piPtr = 3.14159;
    
    // 5
    cout << "Modified pi: " << pi << endl; // القيمة تغيرت بنجاح

    return 0;
}
```

</details>

<SummaryBox title="📌 Lesson Summary">

- المتغيرات تعيش في الذاكرة، وكل متغير له عنوان (Address).
- الـ **Pointer** هو متغير يحفظ عناوين المتغيرات الأخرى.
- نستخدم `&` للحصول على عنوان متغير.
- نستخدم `*` لتعريف المؤشر، ونستخدمها أيضاً للوصول/لتعديل القيمة التي يشير إليها (Dereference).
- لتفادي الأخطاء الكارثية، دائماً اجعل المؤشر الفارغ يشير إلى `nullptr`.

</SummaryBox>
