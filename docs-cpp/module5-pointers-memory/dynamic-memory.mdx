# 5.2 إدارة الذاكرة الديناميكية (Dynamic Memory)

في البرامج البسيطة التي كتبناها، كان الكمبيوتر يحجز الذاكرة للمتغيرات والمصفوفات تلقائياً عند تشغيل البرنامج (في منطقة تسمى Stack)، ويزيلها تلقائياً عند انتهاء الدالة.
ولكن، ماذا لو كنا لا نعرف حجم المصفوفة التي نحتاجها إلا أثناء عمل البرنامج (مثلاً، بناءً على إدخال المستخدم)؟ هنا نحتاج إلى **الذاكرة الديناميكية (Dynamic Memory)** باستخدام منطقة الـ Heap.

---

## 1. الكلمات المفتاحية: `new` و `delete`

في C++، يتم حجز الذاكرة الديناميكية يدوياً باستخدام كلمة **`new`**، ويجب تنظيفها (تحريرها) يدوياً باستخدام كلمة **`delete`**.

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1. الحجز الديناميكي لمتغير واحد
    int* ptr = new int; // حجزنا مساحة في الـ Heap من نوع int
    
    *ptr = 42; // وضعنا فيها قيمة
    cout << *ptr << endl; // 42
    
    // 2. تحرير الذاكرة (مهم جداً!)
    delete ptr; 
    
    // 3. تأمين المؤشر
    ptr = nullptr;

    return 0;
}
```

### ماذا يحدث إذا نسينا `delete`؟
هذا يؤدي إلى ما يسمى **بتسريب الذاكرة (Memory Leak)**! الذاكرة تظل محجوزة ولا يمكن لأي برنامج آخر استخدامها، وإذا كان برنامجك يعمل لفترة طويلة (كسيرفر أو لعبة)، فإنه سيستهلك كل الـ RAM وسيتوقف فجأة (Crash).

---

## 2. المصفوفات الديناميكية (Dynamic Arrays)

هذا هو الاستخدام الأكثر شيوعاً للذاكرة الديناميكية؛ إنشاء مصفوفة بحجم يحدده المستخدم وقت التشغيل (Runtime).

```cpp
int size;
cout << "How many students? ";
cin >> size;

// لا يمكننا كتابة int students[size] في C++ الكلاسيكية
// لذلك نستخدم الذاكرة الديناميكية:

int* students = new int[size]; // حجز مصفوفة في الـ Heap

// تعبئة المصفوفة
for(int i = 0; i < size; i++) {
    students[i] = i * 10;
}

// تحرير مصفوفة ديناميكية (لاحظ استخدام الأقواس المربعة [])
delete[] students; 
students = nullptr;
```

---

## 3. المؤشرات الذكية (Smart Pointers - C++11)

لأن نسيان `delete` هو خطأ شائع ومدمر، قدمت C++11 حلاً عبقرياً: **المؤشرات الذكية**. 
المؤشر الذكي يقوم بتحرير الذاكرة (`delete`) تلقائياً بمجرد خروجه من النطاق (Scope). لا داعي للقلق بشأن الـ Memory Leaks بعد الآن!

أهم نوعين (يتطلبان مكتبة `<memory>`):
1. **`unique_ptr`**: يمتلك الذاكرة حصرياً (لا يمكن لمؤشر آخر أن يشير لنفس المكان).
2. **`shared_ptr`**: يمكن لعدة مؤشرات الإشارة لنفس المكان، ويتم الحذف عندما يختفي آخر مؤشر.

```cpp
#include <iostream>
#include <memory> // ضروري للـ Smart Pointers
using namespace std;

int main() {
    // إنشاء Unique Pointer (الطريقة الحديثة والآمنة)
    unique_ptr<int> myPtr = make_unique<int>(100);
    
    cout << *myPtr << endl; // يطبع 100
    
    // لا حاجة لكتابة delete هنا أبداً!
    // بمجرد انتهاء الدالة main، سيتم تنظيف myPtr تلقائياً.
    return 0;
}
```

## ⚡ Performance Notes

:::tip بطء الـ Heap مقابل سرعة الـ Stack
الحجز في الـ Stack (مثل `int x = 5;`) فائق السرعة لأنه يتطلب فقط تحريك مؤشر داخلي للمعالج (Stack Pointer). أما الحجز الديناميكي في الـ Heap باستخدام `new`، فهو بطيء جداً، لأن نظام التشغيل (OS) يضطر للبحث في الذاكرة العشوائية عن كتلة متجاورة فارغة تكفي لطلبك.
لذلك، **القاعدة الذهبية في C++:** تجنب استخدام الذاكرة الديناميكية (`new`) إلا إذا كنت مضطراً لذلك (كأن يكون الحجم كبيراً جداً، أو غير معروف وقت الترجمة).
:::

## ⚠️ الأخطاء الشائعة (Common Mistakes)

```cpp
// ❌ 1 - تسريب الذاكرة داخل حلقة (Memory Leak in Loop)
for (int i = 0; i < 1000; i++) {
    int* ptr = new int[100]; // 💥 حجز ذاكرة مراراً وتكراراً دون تحريرها. الـ RAM ستمتلئ بسرعة وسينهار البرنامج!
}

// ❌ 2 - الحذف المزدوج (Double Free)
int* p = new int;
delete p;
delete p; // 💥 محاولة تحرير مساحة تم تحريرها بالفعل تسبب انهيار البرنامج (Crash)

// ❌ 3 - استخدام delete بدلاً من []delete للمصفوفات
int* arr = new int[10];
delete arr; // 💥 هذا يحذف العنصر الأول فقط من المصفوفة!
delete[] arr; // ✅ الصحيح لحذف المصفوفة بالكامل
```

## Interview Questions & Answers

<details>
<summary><strong>Q1: ما هو الـ Dangling Pointer؟</strong></summary>

هو مؤشر يشير إلى عنوان في الذاكرة تم تحريره بالفعل (`deleted`). 
الخطورة: قد يحاول البرنامج قراءة أو كتابة بيانات في هذا العنوان العشوائي مما يسبب انهيار النظام.
**الحل:** بعد أي `delete ptr;`، قم دائماً بتعيين المؤشر إلى `nullptr` هكذا `ptr = nullptr;`.
</details>

<details>
<summary><strong>Q2: ما الفرق بين مساحة الـ Stack ومساحة الـ Heap؟</strong></summary>

- **Stack**: مساحة صغيرة وسريعة جداً. تُخزن فيها المتغيرات المحلية (Local) ويتم إدارتها تلقائياً (تُنظف بمجرد انتهاء الدالة).
- **Heap**: مساحة ضخمة. يتم فيها الحجز الديناميكي (`new`)، ولكنها أبطأ قليلاً وإدارتها مسؤولية المبرمج بالكامل (يجب عمل `delete`)، أو عبر استخدام الـ Smart Pointers.
</details>

دون استخدام `vector` أو `Smart Pointers` (نريد التدريب على الطريقة اليدوية):
1. اطلب من المستخدم إدخال عدد الكتب التي يمتلكها.
2. احجز مصفوفة ديناميكية من نوع `double` لتخزين أسعار هذه الكتب.
3. باستخدام `for`، اطلب منه إدخال سعر كل كتاب.
4. لا تنسَ **تحرير** الذاكرة في النهاية وتصفير المؤشر.

</ExerciseBox>

<details>
<summary><strong>💡 اضغط هنا لرؤية الحل النموذجي</strong></summary>

```cpp
#include <iostream>
using namespace std;

int main() {
    int count;
    cout << "Enter number of books: ";
    cin >> count;

    // حجز الذاكرة الديناميكية
    double* prices = new double[count];

    // إدخال البيانات
    for (int i = 0; i < count; i++) {
        cout << "Enter price for book " << (i + 1) << ": ";
        cin >> prices[i];
    }

    // طباعة رسالة للتحقق
    cout << "You saved prices for " << count << " books." << endl;

    // تحرير الذاكرة وتأمين المؤشر
    delete[] prices;
    prices = nullptr;

    return 0;
}
```

<SummaryBox title="📌 Lesson Summary">

- الذاكرة الديناميكية تُستخدم عند الحاجة لمساحات مجهولة الحجم وقت البرمجة.
- استخدم `new` للحجز و `delete` للتحرير (تذكر `delete[]` للمصفوفات).
- نسيان الـ `delete` يسبب تسريباً للذاكرة (Memory Leak).
- المؤشرات التي تشير لمكان تم حذفه تُسمى Dangling Pointers (احمِ نفسك باستخدام `nullptr`).
- في الـ C++ الحديثة، يُفضل استخدام المؤشرات الذكية (`unique_ptr`) لتجنب أخطاء الذاكرة تماماً.

</SummaryBox>
