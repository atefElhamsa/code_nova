# 4.1 المصفوفات (Arrays)

تخيل أنك تريد تخزين درجات 100 طالب في نظام المدرسة. هل من المنطقي أن نُعرّف 100 متغير منفصل (`int score1, score2 ...`)؟ بالطبع لا.
المصفوفة (Array) هي متغير واحد يمكنه تخزين **مجموعة من القيم من نفس النوع** في مساحات متجاورة في الذاكرة.

---

## 1. تعريف المصفوفة (Array Declaration)

لتعريف مصفوفة، يجب تحديد **النوع**، **الاسم**، و **الحجم** (عدد العناصر).

```cpp
#include <iostream>
using namespace std;

int main() {
    // مصفوفة يمكنها تخزين 4 أرقام صحيحة
    int grades[4] = {85, 90, 78, 92}; 
    
    // يمكنك أيضاً ترك الحجم فارغاً إذا كنت ستعطي القيم فوراً
    string cars[] = {"BMW", "Ford", "Mazda"};
    
    return 0;
}
```

> ⚠️ **ملاحظة:** في C++ الكلاسيكية، **حجم المصفوفة ثابت (Fixed Size)**. بمجرد تعريف مصفوفة بـ 4 عناصر، لا يمكنك إضافة عنصر خامس لاحقاً. (لحل هذه المشكلة سنستخدم `vector` في الدرس القادم).

---

## 2. الوصول إلى عناصر المصفوفة

كل عنصر داخل المصفوفة له **فهرس (Index)**. 
**أهم قاعدة في البرمجة:** الـ Index يبدأ دائماً من **الصفر (0)**، وليس 1!

```cpp
int grades[4] = {85, 90, 78, 92};
//               0   1   2   3  (الفهارس)

cout << grades[0] << endl; // سيطبع 85 (العنصر الأول)
cout << grades[2] << endl; // سيطبع 78 (العنصر الثالث)

// تغيير قيمة عنصر معين
grades[1] = 95; 
cout << grades[1] << endl; // سيطبع 95
```

---

## 3. المرور على عناصر المصفوفة (Looping)

أفضل طريقة للتعامل مع المصفوفات هي استخدام حلقة `for` للمرور على جميع العناصر وطباعتها أو التعديل عليها.

```cpp
int grades[5] = {85, 90, 78, 92, 88};

for (int i = 0; i < 5; i++) {
    cout << "Grade " << i + 1 << ": " << grades[i] << endl;
}
```

### استخدام `for-each` (المدعومة في C++11 وما بعدها)
طريقة أنظف وأسهل للمرور على جميع العناصر دون القلق بشأن حجم المصفوفة أو الفهارس (Indexes):

```cpp
int grades[5] = {85, 90, 78, 92, 88};

// تُقرأ: لكل grade موجود بداخل مصفوفة grades
for (int grade : grades) {
    cout << grade << " ";
}
```

---

## 4. المصفوفات ثنائية الأبعاد (2D Arrays)

يمكنك إنشاء مصفوفة داخل مصفوفة (تشبه الشبكة أو الجدول الذي يتكون من صفوف وأعمدة). تُستخدم بكثرة في الألعاب (مثل الشطرنج) والجداول.

```cpp
// مصفوفة من 2 صفوف و 3 أعمدة
int matrix[2][3] = {
    {1, 2, 3}, // الصف رقم 0
    {4, 5, 6}  // الصف رقم 1
};

// الوصول للعنصر في الصف 1 والعمود 2
cout << matrix[1][2]; // سيطبع 6
```
للمرور على عناصر مصفوفة ثنائية الأبعاد، نحتاج إلى حلقتين متداخلتين (Nested Loops):

```cpp
for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 3; col++) {
        cout << matrix[row][col] << " ";
    }
    cout << endl; // سطر جديد بعد كل صف
}
```

## ⚡ Performance Notes

:::tip محلية الذاكرة (Cache Locality)
لماذا تعتبر المصفوفات (Arrays) سريعة جداً في C++؟ السر يكمن في طريقة تخزينها. عناصر المصفوفة تُخزن في الذاكرة (RAM) بشكل متجاور (Contiguous). عندما يطلب المعالج العنصر الأول، يتم جلب العناصر المجاورة له أيضاً إلى ذاكرة التخزين المؤقت السريعة جداً (CPU Cache). هذا يقلل من الوقت الضائع في جلب البيانات من الرام بشكل فردي ويجعل الوصول للمصفوفات أسرع بكثير من هياكل البيانات الأخرى.
:::

## ⚠️ الأخطاء الشائعة (Common Mistakes)

```cpp
// ❌ 1 - الخروج عن حدود المصفوفة (Out of Bounds)
int arr[5] = {1, 2, 3, 4, 5};
for (int i = 0; i <= 5; i++) { // 💥 خطأ: i يجب أن تكون أصغر تماماً من 5 (< 5) وليس (<=)
    cout << arr[i]; // سيطبع قيمة عشوائية عندما تصل i إلى 5
}

// ❌ 2 - استخدام متغير لتحديد حجم المصفوفة الكلاسيكية
int size = 10;
int myArr[size]; // 💥 خطأ في C++ القياسية: حجم المصفوفة العادية يجب أن يكون رقماً ثابتاً (Const) معروفاً وقت الترجمة
// ✅ الحل: استخدام std::vector إذا كان الحجم متغيراً.
```

## Interview Questions & Answers

<details>
<summary><strong>Q1: ماذا يحدث إذا حاولنا الوصول لعنصر خارج حدود المصفوفة (مثال: `grades[10]`)؟</strong></summary>

في لغات مثل Java أو Python، ستحصل على خطأ مباشر يوقف البرنامج (Out of Bounds Exception). 
لكن C++ **لا تتحقق من الحدود** لأسباب تتعلق بالسرعة! الوصول لفهرس غير موجود سيعطيك "Garbage Value" (قيمة عشوائية من الذاكرة)، وإذا حاولت تعديلها قد تتسبب في انهيار البرنامج بالكامل (Segmentation Fault) وتعديل بيانات برامج أخرى.
</details>

<ExerciseBox title="🏋️ Exercise - حساب متوسط الدرجات">

قم بإنشاء مصفوفة تحتوي على 5 أرقام عشرية (تمثل درجات طالب).
استخدم حلقة `for` لجمع كل هذه الدرجات في متغير اسمه `sum`.
بعد الحلقة، احسب المتوسط `average` (المجموع مقسوماً على 5) واطبعه.

</ExerciseBox>

<details>
<summary><strong>💡 اضغط هنا لرؤية الحل النموذجي</strong></summary>

```cpp
#include <iostream>
using namespace std;

int main() {
    double grades[5] = {85.5, 90.0, 78.5, 92.5, 88.0};
    double sum = 0;

    // المرور على المصفوفة لجمع الدرجات
    for (int i = 0; i < 5; i++) {
        sum += grades[i]; // sum = sum + grades[i]
    }

    // حساب المتوسط
    double average = sum / 5;

    cout << "Total Sum: " << sum << endl;
    cout << "Average Grade: " << average << endl;

    return 0;
}
```

</details>

<SummaryBox title="📌 Lesson Summary">

- المصفوفات تخزن أكثر من قيمة من نفس النوع في متغير واحد.
- الفهرس (Index) يبدأ دائماً من `0`.
- حجم المصفوفة في C++ ثابت ولا يتغير بعد التعريف.
- C++ لا تمنعك من الخروج عن حدود المصفوفة، وهذه مسؤولية المبرمج!
- حلقة `for-each` تعتبر الطريقة الأنظف والأكثر أماناً لقراءة المصفوفات.

</SummaryBox>
