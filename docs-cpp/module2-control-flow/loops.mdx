# 2.2 الحلقات التكرارية (Loops)

تُستخدم الحلقات التكرارية لتنفيذ كتلة من الأكواد عدة مرات طالما أن هناك شرطاً معيناً لا يزال صحيحاً. هذا يوفر علينا كتابة نفس الكود عشرات أو مئات المرات.

---

## 1. حلقة `for` (For Loop)

تُستخدم عندما نكون **نعرف مسبقاً عدد المرات** التي نريد تكرار الكود فيها.

**صيغة `for` تحتوي على 3 أقسام:**
`for(بداية العداد; شرط الاستمرار; التحديث)`

```cpp
#include <iostream>
using namespace std;

int main() {
    // سيطبع الأرقام من 1 إلى 5
    for (int i = 1; i <= 5; i++) {
        cout << i << " ";
    }
    // Output: 1 2 3 4 5
    return 0;
}
```

### كيف تعمل؟
1. **`int i = 1`**: يتم تنفيذها مرة واحدة فقط في البداية (إعداد العداد).
2. **`i <= 5`**: قبل كل دورة يتم التحقق من هذا الشرط. إذا كان صحيحاً ندخل الحلقة.
3. يتم تنفيذ الكود بداخل الحلقة (`cout`).
4. **`i++`**: في نهاية الدورة يتم تحديث العداد، ثم العودة لخطوة 2.

---

## 2. حلقة `while` (While Loop)

تُستخدم عندما نكون **لا نعرف عدد المرات** بالتحديد، ونريد أن تتكرر الحلقة طالما أن الشرط صحيح (true).

```cpp
int counter = 1;
while (counter <= 5) {
    cout << counter << " ";
    counter++; // مهم جداً وإلا ستستمر الحلقة للأبد (Infinite Loop)
}
```

> ⚠️ **خطر الـ Infinite Loop:** في حلقة `while`، إذا نسيت تحديث المتغير الذي تعتمد عليه في الشرط (مثل عدم كتابة `counter++`)، فلن ينتهي البرنامج أبداً وقد يؤدي لتوقف النظام (Crash).

---

## 3. حلقة `do-while`

تعمل بنفس طريقة `while`، ولكن الفارق الوحيد أن الكود الذي بداخلها سيتم تنفيذه **مرة واحدة على الأقل** قبل حتى أن يتم التحقق من الشرط.

```cpp
int i = 10;
do {
    cout << i << " "; // سيطبع 10 مع أن الشرط غير متحقق!
    i++;
} while (i < 5); // التحقق يتم في النهاية
```
تُستخدم غالباً في عمل الـ Menus (القوائم)، لأننا نحتاج إظهار القائمة للمستخدم مرة واحدة على الأقل قبل أخذ اختياره والتأكد منه.

---

## 4. التحكم في الحلقة: `break` و `continue`

- **`break`**: تخرجك من الحلقة فوراً وبشكل كامل.
- **`continue`**: تتجاهل ما تبقى من الدورة الحالية، وتنتقل مباشرة إلى الدورة التي تليها (Next iteration).

```cpp
for (int i = 1; i <= 10; i++) {
    if (i == 3) {
        continue; // سيتجاهل الرقم 3 ولا يطبعه
    }
    if (i == 7) {
        break; // سيتوقف تماماً ويخرج من الحلقة عند 7
    }
    cout << i << " ";
}
// Output: 1 2 4 5 6
```

---

## 5. الحلقات المتداخلة (Nested Loops)

هي حلقة داخل حلقة أخرى. الدورة الواحدة من الحلقة الخارجية (Outer loop) تؤدي إلى تنفيذ كل دورات الحلقة الداخلية (Inner loop) بالكامل. تستخدم للتعامل مع الجداول والمصفوفات ثنائية الأبعاد (2D Arrays).

```cpp
for (int i = 1; i <= 3; ++i) {      // الحلقة الخارجية
    cout << "Week: " << i << "\n";
    
    for (int j = 1; j <= 2; ++j) {  // الحلقة الداخلية
        cout << "  Day: " << j << "\n";
    }
}
```
**النتيجة:**
```
Week: 1
  Day: 1
  Day: 2
Week: 2
  Day: 1
  Day: 2
Week: 3
  Day: 1
  Day: 2
```

---

## ⚡ Performance Notes

:::tip الحلقات المتداخلة والأداء (Time Complexity)
استخدام الحلقات المتداخلة (Nested Loops) يرفع تعقيد الوقت (Time Complexity) إلى $O(N^2)$ أو أكثر. هذا يعني أنه إذا كان لديك قائمة بها 1000 عنصر وقمت بحلقة داخل حلقة، سينفذ الكود مليون عملية (1,000,000). دائماً اسأل نفسك: "هل يمكنني فعل هذا بحلقة واحدة (استخدام HashMap مثلاً) بدلاً من حلقتين؟".
:::

## Interview Questions & Answers

<details>
<summary><strong>Q1: متى نستخدم `while` ومتى نستخدم `for` في الواقع العملي؟</strong></summary>

تُفضل `for` عندما يكون لدينا هيكل بيانات بحجم معروف (مثل مصفوفة أو Vector) أو عدد خطوات محدد.
بينما تُفضل `while` عند انتظار حدث (Event) لا نعرف متى سيقع، مثل: طالما أن المستخدم لم يضغط زر الخروج (`while(isRunning)`).
</details>

<details>
<summary><strong>Q2: ما هو الـ Infinite Loop وهل له استخدام مفيد؟</strong></summary>

الـ Infinite loop هو حلقة لا تنتهي أبداً. رغم أنه غالباً خطأ برمجي، إلا أنه يُستخدم عمداً في برمجة السيرفرات (للاستماع المستمر للطلبات) ومحركات الألعاب (Game Loop) لتحديث الشاشة باستمرار باستخدام `while(true)`.
</details>

## ⚠️ الأخطاء الشائعة (Common Mistakes)

```cpp
// ❌ 1 - وضع فاصلة منقوطة بعد جملة for
for (int i = 0; i < 5; i++); // 💥 هذه الفاصلة تنهي الحلقة هنا!
{
    cout << i; // هذا الكود أصبح خارج الحلقة تماماً
}

// ❌ 2 - نسيان تحديث المتغير في حلقة while
int counter = 0;
while (counter < 5) {
    cout << counter;
    // 💥 خطأ: نسينا كتابة counter++ مما سيؤدي إلى حلقة لا نهائية تطبع 0 للأبد!
}
```

<SummaryBox title="📌 Lesson Summary">

- استخدم `for loop` عندما تعرف عدد التكرارات مسبقاً.
- استخدم `while` عندما يعتمد التكرار على شرط متغير.
- استخدم `do-while` إذا أردت التنفيذ مرة واحدة على الأقل قبل التحقق.
- `break` تُنهي الحلقة، بينما `continue` تتخطى دورة واحدة.
- يمكن دمج أكثر من حلقة داخل بعضها (Nested Loops).

</SummaryBox>
