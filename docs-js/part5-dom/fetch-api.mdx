# 5.3 جلب البيانات من الخوادم (Fetch API)

كيف تقوم التطبيقات الحديثة بجلب تغريدات جديدة أو إرسال رسائل دون إعادة تحميل الصفحة؟ الجواب هو استخدام تقنية الـ AJAX. وفي جافاسكريبت الحديثة، الأداة الأساسية للقيام بذلك هي الدالة المدمجة الرائعة `fetch()`.

---

##  الأهداف التعليمية

1. استخدام دالة `fetch()` لجلب البيانات (GET) من خادم خارجي (API).
2. دمج الـ Fetch بسلاسة مع `async/await` للتعامل مع الـ Promises.
3. تحويل الرد إلى صيغة قابلة للاستخدام (`json()`).
4. إرسال البيانات للخادم (POST Request).

---

## 1. ما هو الـ Fetch API؟

وظيفة `fetch` هي واجهة برمجة مدمجة (Built-in) في المتصفح تسمح لنا بإجراء طلبات (HTTP Requests) لجلب أو إرسال بيانات إلى خوادم خارجية عبر الإنترنت بدون تحديث الصفحة.

> 💡 **مقارنة بـ Dart/Flutter:**
> دالة `fetch` هي المقابل المباشر لحزمة `http` أو مكتبة `dio` في Flutter.

الدالة `fetch()` تُرجع دائماً **Promise**، لذلك نستخدمها دائماً مع صديقتها المخلصة `async/await`.

---

## 2. جلب البيانات (GET Request)

الطلب الافتراضي لـ `fetch` هو جلب البيانات. لنقم بجلب قائمة مستخدمين وهمية من الـ API المجاني المشهور (JSONPlaceholder).

```javascript
async function getUsers() {
  try {
    // 1. طلب البيانات من الرابط (الانتظار حتى يجيب الخادم)
    const response = await fetch("https://jsonplaceholder.typicode.com/users");
    
    // 2. فحص حالة الرد (مهم!)
    if (!response.ok) throw new Error("Network response was not ok");

    // 3. تحويل الرد إلى صيغة JSON (الانتظار حتى ينتهي التحويل)
    const data = await response.json();
    
    // 4. استخدام البيانات الحقيقية
    console.log("Users fetched:", data[0].name); // اسم أول مستخدم
  } catch (error) {
    console.error("Error fetching users:", error);
  }
}

getUsers();
```

> **ملاحظة محورية:** نستخدم `await` مرتين! المرة الأولى لجلب الرد الخام من الشبكة، والمرة الثانية لتحويل الرد من شكل "تيار بيانات" (Stream) غير مقروء إلى كائن جافاسكريبت واضح باستخدام `response.json()`.

---

## 3. إرسال البيانات (POST Request)

لإرسال بيانات إلى الخادم (مثل إنشاء حساب مستخدم جديد أو كتابة تعليق)، نُمرر كائناً ثانياً (Options Object) لدالة `fetch` يحتوي على إعدادات الطلب مثل الـ `Method`, الـ `Headers`، والـ `Body`.

```javascript
async function createUser() {
  const newUser = {
    name: "Ahmed",
    job: "Flutter Developer"
  };

  try {
    const response = await fetch("https://jsonplaceholder.typicode.com/users", {
      method: "POST", // تحديد نوع الطلب لإرسال البيانات
      headers: {
        "Content-Type": "application/json" // إخبار الخادم أن البيانات نوعها JSON
      },
      body: JSON.stringify(newUser) // تحويل الكائن الخاص بنا إلى نص JSON مقروء للخادم
    });

    const result = await response.json(); // قراءة رد الخادم
    console.log("User created successfully:", result);
  } catch (error) {
    console.error("Error creating user:", error);
  }
}
```

> 💡 **مقارنة بـ Dart:** دالة `JSON.stringify()` في جافاسكريبت تعادل دالة `jsonEncode()` في لغة Dart!

## ⚡ Performance Notes

:::tip استخدام AbortController لإلغاء الطلبات
ماذا لو قام المستخدم بالانتقال لصفحة أخرى أو ضغط زر الإلغاء بينما لا يزال الـ `fetch` يجلب البيانات؟ الـ Fetch لا يتوقف من تلقاء نفسه وسيستمر في استهلاك موارد الجهاز! في التطبيقات الاحترافية، نستخدم `AbortController` لإلغاء الطلب فوراً إذا لم نعد بحاجة إليه.
:::

## ⚠️ الأخطاء الشائعة (Common Mistakes)

```javascript
// ❌ 1 - نسيان الانتظار عند تحويل الـ JSON
const response = await fetch(url);
const data = response.json(); // 💥 خطأ: نسينا كلمة await
console.log(data); // سيطبع كائن Promise وليس البيانات الحقيقية!

// ❌ 2 - الاعتقاد بأن fetch ترمي خطأ (Reject) عند أخطاء الـ HTTP (مثل 404 أو 500)
// الـ fetch يرمي خطأ فقط في حالة انقطاع الإنترنت! إذا رد السيرفر بـ 404 سيعتبره نجاحاً!
const response = await fetch("bad-url");
// ✅ الحل: يجب فحص خاصية ok يدوياً
if (!response.ok) { throw new Error("HTTP Status Error: " + response.status); }
```

## Interview Questions & Answers

<details>
<summary><strong>Q1: هل يمكن للـ Fetch أن يتتبع نسبة التقدم (Upload/Download Progress)؟</strong></summary>

لا، الـ Fetch API الأصلي لا يوفر طريقة سهلة لمراقبة نسبة تحميل أو رفع الملفات بشكل مدمج. للحصول على هذه الميزة بسهولة، يلجأ المطورون عادةً لاستخدام مكتبة خارجية شهيرة تسمى **Axios** (والتي تبنى فوق كائن XMLHttpRequest الأقدم الذي يدعم هذه الميزة).
</details>

5. اطبع الـ `title` الخاص بأول بوست في المصفوفة الراجعة.

<details>
<summary><strong>💡 اضغط هنا لرؤية الحل (Solution)</strong></summary>

```javascript
const getFirstPost = async () => {
  try {
    const response = await fetch("https://jsonplaceholder.typicode.com/posts");
    
    if (!response.ok) {
      throw new Error(`Server error: ${response.status}`);
    }

    const posts = await response.json();
    
    // طباعة عنوان أول بوست
    console.log("First post title:", posts[0].title);
    
  } catch (error) {
    console.error("Network Error:", error.message);
  }
};

getFirstPost();
```

<SummaryBox title="📌 ملخص الدرس (Summary)">

- الـ `fetch()` هي الأداة القياسية الحديثة لتبادل البيانات مع الخوادم.
- لأنها تُرجع وعوداً (Promises) يتم استخدامها دائماً مع `async/await`.
- لتحويل الرد لبيانات جافاسكريبت حقيقية، لا تنسَ استخدام `await response.json()`.
- الـ Fetch لا يقع في الـ `catch` عند رجوع أخطاء مثل 404 من الخادم، بل يجب التحقق من `response.ok`.
- عند إرسال بيانات (POST)، تأكد من إعداد الـ Headers وتحويل البيانات باستخدام `JSON.stringify()`.

</SummaryBox>
