# 1.1 المتغيرات في جافاسكريبت (Variables)

في هذا الدرس الأول، ستتعلم كيف تخزن البيانات في جافاسكريبت باستخدام المتغيرات. جافاسكريبت تمتلك طرقاً مختلفة لتعريف المتغيرات (`var`, `let`, `const`)، وفهم الفرق بينها هو أول خطوة لاحتراف لغة جافاسكريبت الحديثة.

---

##  الأهداف التعليمية

1. الإعلان عن المتغيرات بأساليب جافاسكريبت الثلاثة: `var`, `let`, `const`.
2. فهم الفرق الجوهري بين `let` و `const` ومتى تستخدم كلاً منهما.
3. استيعاب مشاكل الـ `var` القديمة ولماذا نتجنبها في الكود الحديث.
4. الإجابة على أسئلة المقابلات الشخصية (Interview Questions) المتعلقة بالمتغيرات.

---

## 1. ما هو المتغير (Variable)؟

المتغير ببساطة هو **صندوق في ذاكرة الكمبيوتر (RAM)** تُعطيه اسماً، وتضع بداخله قيمة (رقم، نص، الخ) لتتمكن من استخدامها أو تعديلها لاحقاً في الكود.

```javascript
// اسم المتغير = userName
// قيمته = "Ahmed"
let userName = "Ahmed";

// اسم المتغير = age
// قيمته = 25
let age = 25;
```

---

## 2. الطريقة الحديثة: `let` و `const` (ES6)

بداية من عام 2015 (تحديث ES6)، أضافت جافاسكريبت طريقتين جديدتين وأكثر أماناً لتعريف المتغيرات:

### استخدام `let` (المتغيرات القابلة للتعديل)
تستخدم `let` عندما تعرف أن قيمة المتغير **سوف تتغير** لاحقاً.

```javascript
let score = 0;
console.log(score); // 0

score = 10; // ✅ تغيير القيمة مسموح
console.log(score); // 10
```

### استخدام `const` (الثوابت)
تستخدم `const` (اختصار Constant) عندما تريد تخزين قيمة **لن تتغير أبداً**.

```javascript
const birthYear = 1998;
console.log(birthYear); // 1998

birthYear = 2000; // ❌ TypeError: Assignment to constant variable.
```

> ✅ **قاعدة الكود النظيف (Clean Code):** استخدم دائماً `const` كخيار افتراضي لكل متغيراتك. إذا اكتشفت لاحقاً أن المتغير يحتاج لتغيير قيمته، قم بتغييره إلى `let`. هذا يقلل من الأخطاء غير المتوقعة (Bugs).

---

## 3. ماذا عن `var`؟ (الطريقة القديمة)

قبل عام 2015، كانت `var` هي الطريقة الوحيدة لتعريف المتغيرات. 

```javascript
var oldWay = "Hello World";
```

### لماذا نتجنب `var` اليوم؟
الـ `var` تسبب الكثير من المشاكل بسبب طريقة تعاملها مع الـ Scope (سندرس الـ Scope بالتفصيل في الدرس 1.5). 
أحد أسوأ عيوبها هو أنها تسمح بإعادة تعريف نفس المتغير مرتين بدون أي تنبيه!

```javascript
// استخدام var (طريقة سيئة)
var email = "test@test.com";
var email = "admin@test.com"; // ✅ لن يظهر أي خطأ! وسيقوم بالكتابة فوقه!

// استخدام let (الطريقة الصحيحة)
let password = "123";
let password = "456"; // ❌ SyntaxError: Identifier 'password' has already been declared
```

---

## 4. شروط تسمية المتغيرات في JS

1. يمكن أن يحتوي على حروف، أرقام، `_`، و `$`.
2. **لا يمكن** أن يبدأ برقم (`let 1name = "Ahmed"` ❌).
3. حساس لحالة الأحرف (Case Sensitive): `age` يختلف تماماً عن `Age`.
4. لا يمكن استخدام الكلمات المحجوزة في اللغة (مثل `let`, `if`, `function`).

> ✅ **قاعدة الكود النظيف (Clean Code):** في جافاسكريبت، المعيار الذهبي لتسمية المتغيرات هو **camelCase** (الكلمة الأولى بحروف صغيرة، وبداية كل كلمة تالية بحرف كبير). مثال: `firstName`, `totalOrderPrice`.

## 🚀 Performance & Pro Tips

:::tip متى تستخدم const مع المصفوفات (Arrays) والكائنات (Objects)؟
استخدام `const` يمنع **إعادة التعيين بالكامل** (Reassignment)، ولكنه **لا يمنع تعديل المحتوى الداخلي** للمصفوفات والكائنات!

```javascript
const fruits = ["Apple", "Banana"];
fruits.push("Orange"); // ✅ مسموح! تعديل المحتوى
console.log(fruits);   // ["Apple", "Banana", "Orange"]

fruits = ["Mango"];    // ❌ غير مسموح! إعادة تعيين المتغير بالكامل
```
:::

:::tip لا تنسَ تعريف المتغيرات
في جافاسكريبت، إذا كتبت اسم متغير وأسندت له قيمة بدون استخدام `let`, `const`, أو `var`، سيتم إنشاؤه كمتغير عام (Global Variable)، وهذا يعتبر من أسوأ الممارسات.
```javascript
// ❌ خطأ كارثي
userCount = 50; 

// ✅ الطريقة الصحيحة
let userCount = 50;
```
:::

##  أسئلة المقابلات الشخصية (Interview Questions)

<details>
<summary><strong>Q1: ما الفرق بين `var` و `let` و `const`؟</strong></summary>

| | `var` (قديم) | `let` (حديث) | `const` (حديث) |
|---|---|---|---|
| **إعادة التعيين (Reassign)** | ✅ مسموح | ✅ مسموح | ❌ ممنوع |
| **إعادة التعريف (Redeclare)** | ✅ مسموح (مما يسبب مشاكل) | ❌ ممنوع في نفس النطاق | ❌ ممنوع |
| **النطاق (Scope)** | Function Scope (أو Global) | Block Scope | Block Scope |
| **الرفع (Hoisting)** | يُرفع بقيمة `undefined` | يُرفع ولا يمكن استخدامه (TDZ) | يُرفع ولا يمكن استخدامه (TDZ) |

**الإجابة المثالية:** "`const` تستخدم للقيم الثابتة ولا يمكن إعادة تعيينها، `let` للقيم المتغيرة، وكلاهما Block-Scoped. أما `var` فهي الطريقة القديمة وتكون Function-Scoped وتسمح بإعادة التعريف مما يجعلنا نتجنبها في الكود الحديث لتفادي الأخطاء."
</details>

<details>
<summary><strong>Q2: هل `const` تعني أن القيمة غير قابلة للتغيير تماماً (Immutable)؟</strong></summary>

**لا.** كلمة `const` تمنع فقط **إعادة التعيين المباشر** للمتغير نفسه. ولكن إذا كانت القيمة عبارة عن Object أو Array، فيمكنك تعديل الخصائص أو العناصر بداخلها (Mutating). لجعل الـ Object غير قابل للتغيير تماماً، يجب استخدام `Object.freeze()`.
</details>

##  أخطاء شائعة تجنبها (Common Mistakes)

```javascript
// ❌ 1 - استخدام حروف أو أسماء غير واضحة
let a = 10;
let x = true;

// ✅ استخدام أسماء معبرة (Descriptive Names)
let maxUsers = 10;
let isUserLoggedIn = true;

// ❌ 2 - استخدام var بدلاً من let/const
var price = 99;

// ✅
let price = 99;

// ❌ 3 - محاولة تغيير قيمة const
const MAX_LIMIT = 100;
MAX_LIMIT = 200; // سيؤدي إلى تعطل التطبيق!
```

3. عرّف مصفوفة تحتوي على لغات البرمجة التي تعرفها (بطريقة تمنع إعادة تعيين المتغير، ولكن تسمح بإضافة لغات جديدة لاحقاً).

5. قم بإضافة "JavaScript" إلى مصفوفة اللغات.

<details>
<summary><strong>💡 اضغط هنا لرؤية الحل (Solution)</strong></summary>

```javascript
// 1. الاسم لا يتغير، لذا نستخدم const
const myName = "Ali";

// 2. العمر سيتغير، لذا نستخدم let
let myAge = 20;

// 3. المصفوفة لن نعيد تعيينها بالكامل، لذا نستخدم const
const myLanguages = ["Dart", "Python"];

// 4. تعديل العمر مسموح لأننا استخدمنا let
myAge = myAge + 1; // أو myAge++

// 5. تعديل محتوى المصفوفة مسموح حتى مع const
myLanguages.push("JavaScript");

console.log(myName);       // "Ali"
console.log(myAge);        // 21
console.log(myLanguages);  // ["Dart", "Python", "JavaScript"]
```

<SummaryBox title="📌 ملخص الدرس (Summary)">

- المتغيرات هي مساحات في الذاكرة لتخزين البيانات.
- `let`: للمتغيرات التي ستتغير قيمتها لاحقاً (Reassignable).
- `const`: للمتغيرات الثابتة التي لن يتم استبدال قيمتها أبداً (اختيارك الافتراضي!).
- `var`: الطريقة القديمة والمليئة بالمشاكل، تجنب استخدامها في الكود الحديث.
- تسمية المتغيرات يجب أن تكون واضحة ومقروءة بصيغة `camelCase`.

</SummaryBox>
