# 3.3 مقدمة إلى الـ Prototypes

لغة Dart مبنية بالكامل على الكلاسات (Class-based OOP). أما جافاسكريبت فهي مبنية على مفهوم مختلف تماماً يُدعى **Prototypal Inheritance**.

في هذا الدرس، سنكشف السر وراء كيفية عمل جافاسكريبت الحقيقية تحت الغطاء، وندرك أن الكلاسات (Classes) التي تعلمناها هي مجرد "واجهة شكلية" (Syntactic Sugar).

---

##  الأهداف التعليمية

1. فهم الآلية الحقيقية التي تعمل بها جافاسكريبت تحت الغطاء (Prototypal Inheritance).
2. إدراك أن الكلاسات في جافاسكريبت هي مجرد غلاف تجميلي.
3. استيعاب فكرة الـ Prototype Chain.
4. الإجابة على أسئلة المقابلات المتقدمة عن بنية جافاسكريبت.

---

## 1. ما هو الـ Prototype؟

في جافاسكريبت، كل كائن (Object) يمتلك خاصية خفية تسمى `[[Prototype]]` (أو يُشار إليها أحياناً بـ `__proto__`). هذا الـ Prototype هو ببساطة **إشارة إلى كائن آخر**. 

إذا حاولت الوصول إلى خاصية أو دالة غير موجودة في الكائن الحالي، ستقوم جافاسكريبت بالبحث عنها في كائن الـ Prototype الخاص به، وإذا لم تجدها ستبحث في الـ Prototype الخاص به... وهكذا حتى تصل إلى `null` (هذا ما يسمى بـ **Prototype Chain**).

---

## 2. الكلاسات مجرد قناع (Syntactic Sugar)

في الدرس الأول من هذا القسم تعلمنا الـ `class`، ولكن هل تعلم أن جافاسكريبت تحت الغطاء لا تملك "كلاسات حقيقية" مثل Dart أو Java؟

الكلمة `class` تمت إضافتها في تحديث ES6 لتبسيط كتابة الكود وجعله مألوفاً للمطورين القادمين من اللغات الأخرى، لكنها في النهاية تترجم إلى دوال (Functions) وتعتمد على الـ Prototypes!

### كلاس جافاسكريبت الحديث:
```javascript
class Animal {
  constructor(name) {
    this.name = name;
  }
  eat() {
    console.log("Eating...");
  }
}
```

### كيف تعمل فعلياً تحت الغطاء (الطريقة القديمة الكلاسيكية):
```javascript
// دالة البناء (Constructor Function)
function Animal(name) {
  this.name = name;
}

// إضافة وظيفة إلى الـ Prototype لتشاركها كل الكائنات!
Animal.prototype.eat = function() {
  console.log("Eating...");
};
```

---

## 3. لماذا يجب أن أهتم؟

بالنسبة لك كمطور Flutter، ستستخدم دائماً الـ `class` ولن تكتب الكود بالطريقة القديمة، فلماذا تحتاج لمعرفة الـ Prototypes؟

- **لحل المشاكل (Debugging):** عندما تطبع كائن في الـ Console في المتصفح، سترى خاصية غريبة اسمها `[[Prototype]]`. من المهم أن تفهم أنها تحتوي على كل الدوال الموروثة بدلاً من الفزع منها.
- **دوال المصفوفات والنصوص:** جميع الدوال التي نستخدمها مثل `map()` أو `filter()` أو `toUpperCase()` لا يتم تكرارها داخل كل مصفوفة جديدة! بل هي في الحقيقة مخزنة في الـ Prototype الخاص بالـ `Array` أو الـ `String` لكي توفر الذاكرة.

```javascript
const arr = [1, 2, 3];
// arr تمتلك دالة map لأن المصفوفة ترث من Array.prototype
arr.map(x => x * 2);
```

---

## ⚡ Performance Notes

:::tip توفير الذاكرة عبر الـ Prototype
الهدف الرئيسي من الـ Prototypal Inheritance هو تقليل استهلاك الذاكرة. عندما نعرّف دالة مثل `eat()` بداخل الفئة، لا يتم نسخ هذه الدالة 1000 مرة عند إنشاء 1000 كائن مختلف. بدلاً من ذلك، يتم تخزين الدالة **مرة واحدة فقط** في الـ Prototype، وجميع الكائنات الـ 1000 تشير إلى هذه الدالة الموحدة!
:::

## ⚠️ الأخطاء الشائعة (Common Mistakes)

```javascript
// ❌ 1 - العبث بالـ Prototypes المدمجة (Monkey Patching)
// تعديل الـ Prototype للكائنات الأساسية في جافاسكريبت يعتبر من أسوأ الممارسات.
Array.prototype.myCustomLoop = function() { console.log("Hacked!"); }
// 💥 خطأ: هذا قد يكسر مكتبات أخرى تعتمد على الـ Arrays ويدمر الكود الخاص بغيرك!
// ✅ الحل: أنشئ دوالك المساعدة (Helper Functions) بعيداً عن الكائنات المدمجة.

// ❌ 2 - استخدام __proto__ للوصول للبروتوتايب 
// خاصية __proto__ قديمة وبطيئة وتعتبر Deprecated في الكود النظيف.
// ✅ الحل: استخدم Object.getPrototypeOf(obj) للوصول الآمن للبروتوتايب.
```

## Interview Questions & Answers

<details>
<summary><strong>Q1: هل جافاسكريبت لغة Object-Oriented حقيقية؟</strong></summary>

نعم، هي تدعم البرمجة كائنية التوجه، ولكنها ليست (Class-based) مثل Java أو Dart. هي لغة (Prototype-based). أي أن الكائنات ترث من كائنات أخرى مباشرة بدون الحاجة لوجود فئات حقيقية في خلفية اللغة.
</details>

<details>
<summary><strong>Q2: ما هي الـ Prototype Chain وكيف تعمل؟</strong></summary>

هي السلسلة التي تتبعها جافاسكريبت للبحث عن خاصية. عندما تطلب خاصية من كائن، تبحث أولاً في الكائن نفسه. إذا لم تجدها، تذهب للـ `[[Prototype]]` الخاص به. وتستمر في الصعود حتى تصل للـ `Object.prototype`، وإذا لم تجدها هناك، ستصل إلى `null` وترجع `undefined`.
</details>

<details>
<summary><strong>💡 ماذا ستلاحظ؟ (Solution)</strong></summary>

ستلاحظ أن الـ `Array` ترث من `Object`، وأن الـ `Object` يرث من `null`. كل شيء في جافاسكريبت (تقريباً) يعود في النهاية إلى الكائن الأساسي `Object`. هذه هي سلسلة الـ Prototype العظيمة!
</details>

<SummaryBox title="📌 ملخص الدرس (Summary)">

- جافاسكريبت ليست لغة كلاسيكية (Class-based) بل تعتمد على النماذج (Prototypes).
- الكلاسات المضافة في تحديث ES6 هي مجرد طريقة أسهل وشكلية (Syntactic Sugar) لكتابة كود يعتمد على الـ Prototypes.
- الـ **Prototype Chain** هي الآلية التي تورث وتشارك بها جافاسكريبت الخصائص والدوال بين الكائنات لتوفير الذاكرة وتسهيل تناقل البيانات.
- كل كائن يرتبط بكائن آخر مخفي يعتبر "النموذج" الخاص به الذي يأخذ منه الوظائف المشتركة.

</SummaryBox>
