# Intro to Prototypes

## 🎯 Learning Objectives
- فهم الآلية الحقيقية التي تعمل بها جافاسكريبت تحت الغطاء (Prototypal Inheritance).
- إدراك أن الكلاسات (Classes) في جافاسكريبت هي مجرد "واجهة شكلية" (Syntactic Sugar).

---

## 1. ما هو الـ Prototype؟

لغة Dart مبنية بالكامل على الكلاسات (Class-based OOP). أما جافاسكريبت فهي مبنية على مفهوم مختلف تماماً يُدعى **Prototypal Inheritance**.

في جافاسكريبت، كل كائن (Object) يمتلك خاصية خفية تسمى `[[Prototype]]` (أو `__proto__`). هذا الـ Prototype هو ببساطة إشارة إلى كائن آخر. 
إذا حاولت الوصول إلى خاصية أو دالة غير موجودة في الكائن الحالي، ستقوم جافاسكريبت بالبحث عنها في كائن الـ Prototype الخاص به، وإذا لم تجدها ستبحث في الـ Prototype الخاص به... وهكذا حتى تصل إلى `null` (هذا ما يسمى بـ Prototype Chain).

## 2. الكلاسات مجرد قناع (Syntactic Sugar)

في الدرس الأول من هذا القسم تعلمنا الـ `class`، ولكن هل تعلم أن جافاسكريبت تحت الغطاء لا تملك "كلاسات حقيقية" مثل Dart أو Java؟

الكلمة `class` تمت إضافتها في ES6 لتبسيط كتابة الكود وجعله مألوفاً للمطورين القادمين من اللغات الأخرى، لكنها في النهاية تترجم إلى دوال (Functions) وتعتمد على الـ Prototypes!

### كلاس جافاسكريبت الحديث:
```javascript
class Animal {
  constructor(name) {
    this.name = name;
  }
  eat() {
    console.log("Eating...");
  }
}
```

### كيف تعمل فعلياً تحت الغطاء (الطريقة القديمة):
```javascript
// دالة البناء
function Animal(name) {
  this.name = name;
}

// إضافة وظيفة إلى الـ Prototype لتشاركها كل الكائنات
Animal.prototype.eat = function() {
  console.log("Eating...");
};
```

---

## 3. لماذا يجب أن أهتم؟

بالنسبة لك كمطور Flutter، ستستخدم دائماً الـ `class` ولن تكتب الكود بالطريقة القديمة، فلماذا تحتاج لمعرفة الـ Prototypes؟

- **لحل المشاكل (Debugging):** عندما تطبع كائن في الـ Console في المتصفح، سترى خاصية غريبة اسمها `[[Prototype]]`. من المهم أن تفهم أنها تحتوي على كل الدوال الموروثة.
- **دوال المصفوفات والنصوص:** جميع الدوال التي نستخدمها مثل `map()` أو `filter()` أو `toUpperCase()` هي في الحقيقة مخزنة في الـ Prototype الخاص بالـ `Array` أو الـ `String`!

```javascript
const arr = [1, 2, 3];
// arr تمتلك دالة map لأن المصفوفة ترث من Array.prototype
arr.map(x => x * 2);
```

---

## 💻 جرب بنفسك (Hands-on)
1. افتح متصفحك وافتح الـ Developer Tools (اضغط F12) وانتقل لتبويب Console.
2. اكتب `const arr = [1, 2, 3];` واضغط Enter.
3. اكتب `arr` واضغط Enter ثم افتح السهم المجاور للمصفوفة. 
4. سترى خاصية `[[Prototype]]`. افتحها لتشاهد العشرات من الدوال المدمجة التي ترثها هذه المصفوفة.
