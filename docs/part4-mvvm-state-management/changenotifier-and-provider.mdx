# 4.2 إدارة الحالة بـ ChangeNotifier & Provider

تُعتبر حزمة `provider` الأداة الأكثر انتشاراً وسهولة لحقن ونشر الـ ViewModels في شجرة الودجات.

---

##  أهداف الدرس (Learning Objectives)

1. تزويد الشجرة بـ ChangeNotifierProvider.
2. استخدام Consumer وتحديد نطاقات Re-build.
3. التمييز بين context.read و context.watch و Selector.

---

## 1. مزود الحالة (ChangeNotifierProvider)

### 📘 الشرح النظري
يُغلف `ChangeNotifierProvider` الشاشة الفرعية لإنشاء وإدارة دورة حياة الـ ViewModel وتوفيره للودجات التابعة.

### 💻 التطبيق العملي
```dart
Widget buildProvidedScreen() {
  return ChangeNotifierProvider(
    create: (_) => CounterViewModel(),
    child: const CounterView(),
  );
}
```

---

## 2. مستلك الحالة (Consumer Widget)

### 📘 الشرح النظري
تُستخدم `Consumer` لإعادة بناء (Re-build) الجزء المحتاج فقط من الواجهة عند استدعاء `notifyListeners()`.

### 💻 التطبيق العملي
```dart
Consumer<CounterViewModel>(
  builder: (context, vm, child) {
    return Text('Count: ${vm.count}');
  },
);
```

---

## 3. الاستماع المخصص (Selector)

### 📘 الشرح النظري
تُستخدم `Selector` للاستماع لمتغير محدد دقيق داخل الـ ViewModel وتجاهل التغيرات في باقي المتغيرات.

### 💻 التطبيق العملي
```dart
Selector<CounterViewModel, bool>(
  selector: (_, vm) => vm.isLoading,
  builder: (context, isLoading, child) {
    return isLoading ? const CircularProgressIndicator() : const SizedBox();
  },
);
```

---

##  نصائح الأداء والتحسين (Performance Tips)

:::tip استخدام Selector للـ Re-builds الدقيقة
يمنع `Selector` إعادة رسم الشاشة بأكملها عند تغير متغير فرعي غير مرئي.
:::

---

##  أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. استخدام context.watch داخل زر onPressed
onPressed: () => context.watch<VM>().doSomething()

// ✅ الحل الصحيح
onPressed: () => context.read<VM>().doSomething()

```

---

##  أسئلة وأجوبة المقابلات (Interview Q&A)

<details>
<summary><strong>س1: متى نستخدم context.read ومتى نستخدم context.watch؟</strong></summary>

نستخدم `context.read` داخل الـ Callbacks مثل onPressed، بينما نستخدم `context.watch` داخل طريقة `build()` للاستماع والتفاعل.

</details>

<ExerciseBox title="تمرين عملي - تطبيق Selector 🏋️">
