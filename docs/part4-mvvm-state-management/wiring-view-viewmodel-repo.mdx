# 4.4 الربط التكاملي بين الطبقات (Wiring View - ViewModel - Repository)

ربط الطبقات الثلاث بدقة يضمن استقلالية الكود وسهولة استبدال المستودعات للتجربة دون مساس بالأكواد البصرية.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. حقن المستودع في الـ ViewModel عبر التجريد.
2. توفير الـ ViewModel للواجهة باستخدام Provider.
3. استبدال المستودع الحقيقي بـ Mock Repository بسهولة.

---

## 1. عقد المستودع والمستودع الوهمي (Mock Repository)

### 📘 الشرح النظري
ننشئ عقداً تجريدياً ثم ننشئ تطبيقاً وهمياً لتجربة الواجهة بسرعة دون انتظار جاهزية السيرفر.

### 💻 التطبيق العملي
```dart
abstract class BaseQuoteRepository {
  Future<String> getQuote();
}

class MockQuoteRepository implements BaseQuoteRepository {
  @override
  Future<String> getQuote() async => 'Clean Code is Essential!';
}
```

---

## 2. الـ ViewModel المتلقي للعقد

### 📘 الشرح النظري
يتلقى الـ ViewModel التجريد وليس التنفيذ المباشر لتسهيل التناوب والتجربة.

### 💻 التطبيق العملي
```dart
class QuoteViewModel extends ChangeNotifier {
  final BaseQuoteRepository _repo;
  QuoteViewModel(this._repo);

  String quote = '';
  Future<void> fetch() async {
    quote = await _repo.getQuote();
    notifyListeners();
  }
}
```

---

## ⚡ نصائح الأداء والتحسين (Performance Tips)

:::tip المرونة التامة في الاختبار
تمرير التجريدات يتيح تشغيل الشاشة مع بيانات وهمية سريعة جداً.
:::

## 🐛 أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. إنشاء المستودع داخل الـ ViewModel بشكل مباشر
final repo = ApiQuoteRepository(); // 💥 الربط المباشر الصعب!

// ✅ الحل الصحيح
QuoteViewModel(this._repo); // ✅ Dependency Injection

```
