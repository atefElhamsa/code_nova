# 4.3 دورة حياة الـ ViewModel والتنظيف (ViewModel Lifecycle)

إدارة دورة حياة الـ ViewModel حاسمة لمنع تسريبات الذاكرة (Memory Leaks) وإغلاق كافة الاشتراكات الحية عند تدمير الشاشات.

---

##  أهداف الدرس (Learning Objectives)

1. فهم دورة حياة الـ ViewModel وتوقيت البناء والتنفيذ.
2. استخدام dispose() لإغلاق StreamSubscriptions والـ Controllers.
3. الحماية ضد استدعاء notifyListeners() على كائن ميت.

---

## 1. التهيئة الابتدائية المنهجية (Initialization)

### 📘 الشرح النظري
تُستدعى دوال تهيئة الـ ViewModel فور إقرانها بالواجهة لجلب البيانات الأولية من السيرفر.

### 💻 التطبيق العملي
```dart
class ProductListViewModel extends ChangeNotifier {
  void init() {
    // 1. بدء جلب البيانات المبدئية
    fetchProducts();
  }
}
```

---

## 2. التنظيف وإغلاق الاشتراكات (dispose)

### 📘 الشرح النظري
عند تدمير الشاشة ومغادرة المستخدم، تُستدعى `dispose()`. يجب إغلاق كافة الـ Streams والـ TextControllers لمنع استهلاك الرام.

### 💻 التطبيق العملي
```dart
class SafeViewModel extends ChangeNotifier {
  StreamSubscription? _sub;
  bool _isDisposed = false;

  @override
  void dispose() {
    _isDisposed = true;
    _sub?.cancel(); // إغلاق الاشتراك الحركي لمنع Memory Leak
    super.dispose();
  }
}
```

---

## 3. الحماية أثناء الإخطار (Safe notifyListeners)

### 📘 الشرح النظري
تجنب مناداة `notifyListeners()` بعد مغادرة الشاشة لمنع استثناء `FlutterError: A ViewModel was used after being disposed`.

### 💻 التطبيق العملي
```dart
void safeNotify() {
  if (!_isDisposed && hasListeners) {
    notifyListeners(); // إخطار آمن 100%
  }
}
```

---

##  نصائح الأداء والتحسين (Performance Tips)

:::tip إغلاق الترتيبات دائماً في dispose()
كل `StreamSubscription` أو `Timer` ينبغي إلغاؤه فوراً في دالة `dispose()`.
:::

---

##  أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. مناداة notifyListeners() بعد انتهاء await دون التأكد من بقاء الشاشة حية
await fetchData(); notifyListeners(); // 💥 كراش إذا أُغلقت الشاشة أثناء الجلب!

// ✅ الحل الصحيح
await fetchData(); if (hasListeners) notifyListeners();

```

<details>

  StreamSubscription? _sub;
  @override void dispose() { _sub?.cancel(); super.dispose(); }
}

- التأكد من بقاء المستمعين قبل مناداة `notifyListeners()`.
