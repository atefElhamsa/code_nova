# 1.3 Control Flow & Pattern Matching

في الدرس ده هنتعلم إزاي نتحكم في مسار الكود (Control Flow) - إزاي ناخد قرارات، ونكرر عمليات. ومع إضافة **Pattern Matching** و **Switch Expressions** في Dart 3، الكود بقى أقصر وأنظف بكتير. كل ده هنتعلمه بدون ما نلمس أي Classes لسه!

3. استخدام ميزات Dart 3 القوية: **Switch Expressions** و **Pattern Matching**.

## 1. If-Else Statements

الطريقة الأساسية لاتخاذ القرارات. لو الشرط `true`، نفذ الكود ده، وإلا نفذ التاني.

```dart
void checkScore(int score) {
  if (score >= 90) {
    print('Grade: A');
  } else if (score >= 80) {
    print('Grade: B');
  } else {
    print('Grade: C or below');
  }
}
```

> 💡 **Clean Code Tip:** تجنب الـ nested if-else (if جوه if جوه if) لأنها بتصعب القراءة. استخدم الـ **Guard Clauses** (early return).

**مثال بالـ Guard Clause:**
```dart
void processOrder(double? amount) {
  // Guard clauses
  if (amount == null) return;
  if (amount <= 0) return;

  // Main logic
  print('Processing amount: $amount');
}
```

## 2. Ternary Operator (`? :`)

طريقة مختصرة جداً لـ if-else لما تكون عايز ترجع قيمة بناءً على شرط (Expression وليس Statement).

```dart
int age = 20;

// ❌ Verbose if-else
String status1;
if (age >= 18) {
  status1 = 'Adult';
} else {
  status1 = 'Minor';
}

// ✅ Concise Ternary Operator
String status2 = age >= 18 ? 'Adult' : 'Minor';
```

## 3. Loops (التكرار)

عشان تنفذ كود أكتر من مرة.

### `for` Loop (التقليدي)
لو عارف هتبدأ منين وهتقف فين.
```dart
for (int i = 1; i <= 5; i++) {
  print('Iteration $i');
}
```

### `for-in` Loop (الأفضل للمجموعات)
الطريقة الأنظف للتعامل مع الـ Lists.
```dart
List<String> fruits = ['Apple', 'Banana', 'Mango'];

for (String fruit in fruits) {
  print('I love $fruit');
}
```

### `while` & `do-while` Loops
لو التكرار معتمد على شرط ومش عارف عدد المرات بالضبط.
```dart
int count = 3;

while (count > 0) {
  print('Countdown: $count');
  count--;
}
// Outputs: 3, 2, 1
```

## 4. Enums

الـ Enums بتستخدم لتعريف مجموعة ثابتة من القيم. مفيدة جداً عشان تمنع الأخطاء الإملائية.

```dart
// تعريف الـ Enum
enum OrderStatus { pending, processing, shipped, delivered, cancelled }

void printStatusMessage(OrderStatus status) {
  if (status == OrderStatus.delivered) {
    print('Your order is here!');
  }
}
```

---

## 5. Switch Statements (الطريقة القديمة)

استخدام الـ Switch القديم بيحتاج `case` و `break` كتير.

```dart
void handleStatus(OrderStatus status) {
  switch (status) {
    case OrderStatus.pending:
      print('Waiting for approval');
      break;
    case OrderStatus.shipped:
      print('On the way');
      break;
    default:
      print('Other status');
  }
}
```

---

## 6. Dart 3: Switch Expressions (الطريقة الحديثة 🔥)

الـ Switch Expressions بتخليك ترجع قيمة مباشرة بسطر واحد لكل حالة، بدون `case` ولا `break`.

```dart
String getStatusMessage(OrderStatus status) {
  return switch (status) {
    OrderStatus.pending    => 'Waiting for approval',
    OrderStatus.processing => 'We are preparing your order',
    OrderStatus.shipped    => 'Your order is on the way',
    OrderStatus.delivered  => 'Enjoy your purchase!',
    OrderStatus.cancelled  => 'Order was cancelled',
  };
}
```

**ميزة قوية:** الـ Dart compiler هيجبرك تغطي كل الحالات (Exhaustiveness checking). لو نسيت `OrderStatus.cancelled`، هيديك Compile Error!

## 7. Dart 3: Pattern Matching

الـ Pattern Matching بيخليك تفكك وتختبر البيانات المعقدة بسهولة جداً.

**مثال مع Lists:**
```dart
void checkList(List<int> numbers) {
  switch (numbers) {
    case [1, 2]:
      print('List has 1 and 2 exactly');
    case [1, 2, ...]: // Spread pattern
      print('List starts with 1 and 2');
    case [_, _, _]:
      print('List has exactly 3 elements of any value');
    default:
      print('Something else');
  }
}
```

**مثال مع Records (متغيرات مجمعة):**
```dart
void checkCoordinates((int, int) point) {
  switch (point) {
    case (0, 0):
      print('At the origin');
    case (int x, 0):
      print('On the X axis at $x');
    case (0, int y):
      print('On the Y axis at $y');
    case (int x, int y) when x == y: // Guard clause inside switch
      print('On the diagonal');
    default:
      print('Somewhere else');
  }
}
```

## ⚡ Performance Tips

:::tip Break and Continue
استخدم `break` للخروج من الـ loop مبكراً لو لقيت اللي بتدور عليه، و `continue` لتخطي الـ iteration الحالية لو مش محتاجها. ده بيوفر وقت معالجة (CPU cycles).
```dart
for (int i = 0; i < 1000; i++) {
  if (i == 5) continue; // Skip 5
  if (i == 10) break;   // Stop entirely at 10
  print(i);
}
```
:::

:::tip Exhaustive Switch
استخدام الـ Switch Expressions مع الـ Enums أفضل من if-else لأنه بيضمن إنك مغطي كل الحالات وقت الـ Compilation، وبيكون أسرع في التنفيذ (O(1) غالباً) مقارنة بـ if-else (O(n)).
:::

## 🎤 Interview Questions & Answers

<details>
<summary><strong>Q1: إيه الفرق بين If-Else و Ternary Operator؟</strong></summary>

- `if-else`: هو Statement، يعني بينفذ كود، لكن مش بيرجع قيمة. بتستخدمه للمنطق المعقد أو لما يكون عندك سطور كود كتير.
- `? :`: هو Expression، يعني بيرجع قيمة. بتستخدمه لتعيين قيمة لمتغير بناءً على شرط بسيط، وبيخلي الكود أقصر.

```dart
// Statement
if (isTrue) { doSomething(); } else { doSomethingElse(); }

// Expression
var value = isTrue ? 'Yes' : 'No';
```
</details>

<details>
<summary><strong>Q2: إيه ميزة Switch Expressions المضافة في Dart 3؟</strong></summary>

1. **الإيجاز (Conciseness):** مفيش `case` ولا `break` ولا `return` متكررة.
2. **Exhaustiveness:** الـ Compiler بيتأكد إنك غطيت كل الـ Enum values المحتملة.
3. **Values directly:** بترجع قيمة كـ Expression، فتقدر تعينها لمتغير مباشرة أو تعملها return بسهولة.
</details>

<details>
<summary><strong>Q3: متى أستخدم for-in بدلاً من for التقليدي؟</strong></summary>

استخدم `for-in` لما تكون عايز تمر على كل العناصر في List أو Set ومش مهتم بالـ Index (الترتيب الرقمي) بتاع العنصر. الـ `for-in` أنظف وأقل عرضة لأخطاء الـ (Off-by-one errors).
استخدم `for` التقليدي لو محتاج الـ Index عشان تعدل في الـ List أو تقارن عناصر ببعض.
</details>

<details>
<summary><strong>Q4: إيه هو الـ Pattern Matching في Dart؟</strong></summary>

هو طريقة مختصرة وقوية لاختبار وتفكيك (Destructuring) البيانات. بيسمحلك تتأكد إن الـ data متطابقة مع شكل معين (Pattern)، ولو متطابقة، تقدر تستخرج منها قيم فرعية في خطوة واحدة، زي ما بنعمل مع الـ Records والـ Lists جوه الـ Switch.
</details>

## 🐛 Common Mistakes

```dart
// ❌ 1 - Nested Ternary Operators (Hard to read)
String result = score > 90 ? 'A' : score > 80 ? 'B' : 'C';

// ✅ Better: Use a simple if-else or switch for clarity
String result;
if (score > 90) result = 'A';
else if (score > 80) result = 'B';
else result = 'C';


// ❌ 2 - Forgetting cases in old switch
switch (status) {
  case OrderStatus.pending: // What if it's shipped? No warning!
    print('Pending');
}

// ✅ Better: Use Switch Expressions (Compiler warns if not exhaustive)
var msg = switch (status) {
  OrderStatus.pending => 'Pending',
  _ => 'Other', // Wildcard (_) covers everything else
};


// ❌ 3 - Modifying a list while iterating with for-in
for (var item in items) {
  if (item.isBad) items.remove(item); // 💥 ConcurrentModificationError
}

// ✅ Better: Use removeWhere
items.removeWhere((item) => item.isBad);
```
