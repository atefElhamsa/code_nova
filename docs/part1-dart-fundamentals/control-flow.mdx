# 1.3 التحكم في مسار التنفيذ ومطابقة الأنماط (Control Flow & Pattern Matching)

في هذا الدرس، ستتعلم كيفية التحكم في مسار تنفيذ الأكواد البرمجية (Control Flow)، من خلال اتخاذ القرارات وتكرار العمليات. ومع تقديم ميزات **Pattern Matching** و **Switch Expressions** الحديثة في إصدار Dart 3، أصبح الكود أكثر اختصاراً ونظافة بشكل كبير.

---

##  الأهداف التعليمية

1. استخدام عبارات الشرط التقليدية `if-else` والمعامل الشرطي الثلاثي (Ternary Operator `? :`).
2. تكرار العمليات بكفاءة باستخدام حلقات التكرار: `for`, `for-in`, `while`.
3. استغلال ميزات Dart 3 الحديثة: تعبيرات `Switch Expressions` ومطابقة الأنماط `Pattern Matching`.
4. استخدام التعدادات (Enums) لاتخاذ القرارات بطريقة آمنة ومريحة.
5. الإجابة على أسئلة المقابلات الشخصية (Interview Questions) المتعلقة بالتحكم في مسار التكويد.

## 1. عبارات الشرط (If-Else Statements)

تُعتبر الطريقة الأساسية لاتخاذ القرارات في البرمجة: إذا تحقق الشرط (`true`)، ينفذ المترجم كوداً معيناً، وإلا ينفذ كوداً بديلة:

```dart
void checkScore(int score) {
  if (score >= 90) {
    print('Grade: A');
  } else if (score >= 80) {
    print('Grade: B');
  } else {
    print('Grade: C or below');
  }
}
```

تُستخدم حلقات التكرار لتنفيذ جزء معين من الكود عدة مرات دون الحاجة لتكرار كتابته:

### `for` Loop (التكرار المحسوب التقليدي)
يُستخدم عندما تكون نقطة البداية ونقطة النهاية وعدد المرات معروفاً مسبقاً.
```dart
for (int i = 1; i <= 5; i++) {
  print('Iteration $i');
}
```

### `for-in` Loop (التكرار على القوائم والمجموعات)
الطريقة الأنظف والأحدث للتعامل مع القوائم (Lists) والمجموعات (Collections).
```dart
List<String> fruits = ['Apple', 'Banana', 'Mango'];

for (String fruit in fruits) {
  print('I love $fruit');
}
```

### `while` & `do-while` Loops
يُستخدم التكرار الشرطي عندما يكون التكرار معتمداً على شرط معين دون معرفة عدد المرات المسبق بالظبط.
```dart
int count = 3;

while (count > 0) {
  print('Countdown: $count');
  count--;
}
// المخرجات: 3, 2, 1
```

## 4. التعدادات (Enums)

تُستخدم التعدادات (Enums) لتعريف مجموعة مسبقة وثابتة من القيم لخيارات محددة، وهي مفيدة جداً لمنع الأخطاء الإملائية وتنظيم الكود:

```dart
// تعريف الـ Enum
enum OrderStatus { pending, processing, shipped, delivered, cancelled }

void printStatusMessage(OrderStatus status) {
  if (status == OrderStatus.delivered) {
    print('Your order is here!');
  }
}
```

---

## 5. عبارات Switch التقليدية (Traditional Switch Statements)

كانت طريقة `switch` القديمة تتطلب كتابة كلمات `case` و `break` مكررة لكل حالة:

```dart
void handleStatus(OrderStatus status) {
  switch (status) {
    case OrderStatus.pending:
      print('Waiting for approval');
      break;
    case OrderStatus.shipped:
      print('On the way');
      break;
    default:
      print('Other status');
  }
}
```

---

## 6. ميزة Dart 3: تعبيرات Switch الحديثة (Switch Expressions)

تسمح لك تعبيرات `Switch Expressions` في إصدار Dart 3 بإرجاع قيمة مباشرة بسطر واحد لكل حالة، دون الحاجة لكتابة `case` أو `break`:

```dart
String getStatusMessage(OrderStatus status) {
  return switch (status) {
    OrderStatus.pending    => 'Waiting for approval',
    OrderStatus.processing => 'We are preparing your order',
    OrderStatus.shipped    => 'Your order is on the way',
    OrderStatus.delivered  => 'Enjoy your purchase!',
    OrderStatus.cancelled  => 'Order was cancelled',
  };
}
```

**ميزة الأمان الشامل (Exhaustiveness checking):** يقوم مترجم Dart بإجبارك على تغطية جميع الحالات الممكنة للـ Enum. إذا نسيت إضافة حالة `OrderStatus.cancelled` مثلاً، سيظهر خطأ تجميع فوري لمنع الأخطاء!

## 7. ميزة Dart 3: مطابقة الأنماط (Pattern Matching)

تسمح ميزة مطابقة الأنماط بفك واختبار هيكل البيانات المعقدة باختصار وسلاسة:

**مثال مع القوائم (Lists):**
```dart
void checkList(List<int> numbers) {
  switch (numbers) {
    case [1, 2]:
      print('List has 1 and 2 exactly');
    case [1, 2, ...]: // نمط الانتشار
      print('List starts with 1 and 2');
    case [_, _, _]:
      print('List has exactly 3 elements of any value');
    default:
      print('Something else');
  }
}
```

##  نصائح الأداء والتحسين (Performance Tips)

:::tip الكلمات المفتاحية Break و Continue
استخدم `break` للخروج من حلقة التكرار مبكراً فور العثور على القيمة المطلوبة، واستخدم `continue` لتخطي التكرار الحالي والانتقال للعنصر التالي. هذا يقلل من استهلاك دورات المعالج (CPU cycles).
:::

:::tip التعبيرات الشاملة Exhaustive Switch
استخدام `Switch Expressions` مع التعدادات `Enums` يضمن لك كوداً أسرع في التنفيذ ومضمون الأمان وقت التجميع (Compile Time) مقارنة بالشروط المتعددة `if-else`.
:::

##  أسئلة وأجوبة المقابلات الشخصية (Interview Q&A)

<details>
<summary><strong>س1: ما الفرق بين عبارة If-Else والتعبير الثلاثي (Ternary Operator)؟</strong></summary>

- **عبارة `if-else`:** تُعتبر Statement، تنفذ منطقاً برمجياً ولا ترجع قيمة بشكل مباشر. تُستخدم مع الشروط المعقدة.
- **التعبير الثلاثي `? :`:** يُعتبر Expression، يرجع قيمة مباشرة وتستخدمه لإسناد قيمة لمتغير بناءً على شرط مختصر.

</details>

<details>
<summary><strong>س2: ما هي ميزة Switch Expressions المضافة في إصدار Dart 3؟</strong></summary>

1. **الإيجاز (Conciseness):** عدم الحاجة لكتابة `case` أو `break` أو `return` مكررة.
2. **الفحص الشامل (Exhaustiveness):** يتأكد المترجم من تغطية كافة الحالات الممكنة.
3. **إرجاع قيم مباشرة:** ترجع قيمة كـ Expression مما يتيح إسنادها لمتغير في سطر واحد.

</details>

##  أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1 - الشروط الثلاثية المتداخلة الصعبة القراءة
String result = score > 90 ? 'A' : score > 80 ? 'B' : 'C';

// ✅ البديل الأفضل والأوضح:
String result;
if (score > 90) result = 'A';
else if (score > 80) result = 'B';
else result = 'C';


// ❌ 2 - التعديل على القائمة أثناء التكرار باستخدام for-in
for (var item in items) {
  if (item.isBad) items.remove(item); // 💥 خطأ تعديل متزامن (ConcurrentModificationError)
}

// ✅ الحل الصحيح:
items.removeWhere((item) => item.isBad);
```

// 1. تعريف التعداد (Enum) للوظائف
enum UserRole { admin, editor, viewer, guest }

void main() {
  // 2. تحديد المتغير الحالي
  UserRole currentUser = UserRole.editor;

  // 3. استخدام Switch Expression (Dart 3) لإرجاع النص مباشرة بناءً على الـ Enum

    UserRole.editor => 'Edit Access',
    UserRole.viewer => 'Read Only',
    UserRole.guest => 'Limited Access',

  // 5. إنشاء قائمة الأرقام

  // 6. المرور بحلقة for-in وطباعة الأرقام الزوجية فقط
  print('Even numbers in list:');
  for (final number in numbers) {
    // فحص باقي القسمة على 2
    if (number % 2 == 0) {
      print('- $number');
    }
  }

##  Common Mistakes

```dart
// ❌ 1 - Nested Ternary Operators (Hard to read)
String result = score > 90 ? 'A' : score > 80 ? 'B' : 'C';

// ✅ Better: Use a simple if-else or switch for clarity
String result;
if (score > 90) result = 'A';
else if (score > 80) result = 'B';
else result = 'C';


// ❌ 2 - Forgetting cases in old switch
switch (status) {
  case OrderStatus.pending: // What if it's shipped? No warning!
    print('Pending');
}

// ✅ Better: Use Switch Expressions (Compiler warns if not exhaustive)
var msg = switch (status) {
  OrderStatus.pending => 'Pending',
  _ => 'Other', // Wildcard (_) covers everything else
};


// ❌ 3 - Modifying a list while iterating with for-in
for (var item in items) {
  if (item.isBad) items.remove(item); // 💥 ConcurrentModificationError
}

// ✅ Better: Use removeWhere
items.removeWhere((item) => item.isBad);
```
