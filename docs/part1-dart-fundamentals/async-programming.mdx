# 1.9 البرمجة غير التزامنية (Futures, Streams, Async/Await & Isolates)

تعتمد تطبيقات الهواتف المحمولة الحديثة بشكل أساسي على البرمجة غير التزامنية (Asynchronous Programming). في Dart و Flutter، تُنفذ العمليات غير التزامنية مثل جلب البيانات عبر الشبكة، القراءة من قوافل البيانات المحلية، والاستجابة لتحديثات الواجهة دون تجميد الشاشة (UI Freeze) بفضل نموذج الخيط الواحد وحلقة الأحداث (Event Loop).

---

## 🎯 أهداف الدرس (Learning Objectives)

1. **فهم حلقة الأحداث (Event Loop):** استيعاب كيفية إدارة Dart للمهام عبر طابوري الأحداث: `Microtask Queue` و `Event Queue`.
2. **إتقان الـ Futures:** كتابة كود لاتزامني نظيف باستخدام `Future`، `async`، `await`، و `Future.wait`.
3. **إتقان الـ Streams:** التعامل مع التدفقات البيانات المستمرة، المراقبة (`listen`)، والفرق بين `Single-Subscription` و `Broadcast Stream`.
4. **التكامل المعماري في ViewModel:** إدارة حالات التحميل والأخطاء بأمان بدون تسريبات ذاكرة (`Memory Leaks`).
5. **معالجة المهام الثقيلة (Isolates):** استخدام `Isolates` ودالة `compute()` لنقل الحسابات المعقدة خارج خيط الواجهة الرئيسي.

## 💻 الكود البرمجي أولاً (Code Example First)

<span className="code-first-badge">⚡ Pure English Dart Code (MVVM & Clean Code)</span>

```dart
// ==========================================
// File: lib/presentation/viewmodels/news_viewmodel.dart
// Description: Production-grade ViewModel handling async Futures, 
// Stream subscriptions, safe disposal, and error states.
// Architecture Layer: Presentation (ViewModel)
// ==========================================

import 'dart:async';
import 'package:flutter/foundation.dart';

class NewsViewModel extends ChangeNotifier {
  bool _isLoading = false;
  List<String> _articles = [];
  String? _errorMessage;

  // Stream Subscription reference for cleanup
  StreamSubscription<int>? _tickerSubscription;
  int _liveTickerSeconds = 0;
  bool _isDisposed = false;

  bool get isLoading => _isLoading;
  List<String> get articles => _articles;
  String? get errorMessage => _errorMessage;
  int get liveTickerSeconds => _isLiveTickerSeconds;
  int get _isLiveTickerSeconds => _liveTickerSeconds;

  /// Fetch news articles asynchronously
  Future<void> fetchNewsArticles() async {
    _isLoading = true;
    _errorMessage = null;
    _safeNotifyListeners();

    try {
      // Parallel async execution using Future.wait
      final results = await Future.wait([
        _fetchHeaderTitle(),
        _fetchArticleList(),
      ]);

      final header = results[0] as String;
      final fetchedList = results[1] as List<String>;

      _articles = [header, ...fetchedList];
    } catch (error) {
      _errorMessage = 'Failed to load news articles: ${error.toString()}';
    } finally {
      _isLoading = false;
      _safeNotifyListeners();
    }
  }

  /// Start listening to continuous stream
  void startLiveNewsTicker() {
    _tickerSubscription?.cancel();
    _tickerSubscription = _createTickerStream().listen(
      (seconds) {
        _liveTickerSeconds = seconds;
        _safeNotifyListeners();
      },
      onError: (err) {
        _errorMessage = err.toString();
        _safeNotifyListeners();
      },
    );
  }

  /// Generator Stream method creating periodic events
  Stream<int> _createTickerStream() async* {
    int counter = 0;
    while (!_isDisposed) {
      await Future.delayed(const Duration(seconds: 1));
      yield ++counter;
    }
  }

  Future<String> _fetchHeaderTitle() async {
    await Future.delayed(const Duration(milliseconds: 500));
    return '🔥 Breaking News Today';
  }

  Future<List<String>> _fetchArticleList() async {
    await Future.delayed(const Duration(milliseconds: 800));
    return [
      'Flutter 3.x Released with Dynamic Improvements',
      'Clean Code Principles for Senior Dart Developers',
    ];
  }

  void _safeNotifyListeners() {
    if (!_isDisposed) {
      notifyListeners();
    }
  }

  @override
  void dispose() {
    _isDisposed = true;
    _tickerSubscription?.cancel(); // Prevent memory leak!
    super.dispose();
  }
}
```

## 📘 الشرح التفصيلي للكود (Line-by-Line Technical Explanation)

### 1. إدارة العمليات غير التزامنية التوازية (`Future.wait`)
* **`Future.wait([...])`**: بدلاً من انتظار كل طلب شبكة بالتتابع باستخدام `await` منفصل يضاعف وقت الانظار، تقوم `Future.wait` بتشغيل الطلبين بالتوازي في وقت واحد، مما يختصر وقت تحميل الصفحة بشكل ملحوظ.

### 2. التدفقات المولدات اللاتزامنية (`async*` & `yield`)
* **`Stream<int> _createTickerStream() async*`**: الكلمة المفتاحية `async*` تشير إلى أن الدالة مولدة لتدفق بيانات (`Stream Generator`)، ويتم ضخ الأرقام تدريجياً عبر الزمن باستخدام `yield`.

### 3. الحماية ضد تسريب الذاكرة والأخطاء المعمارية
* **`_tickerSubscription?.cancel();`**: في دالة `dispose()`: إغلاق الاشتراكات عند تدمير الشاشة حاسم جداً لتفادي تسريب الذاكرة (`Memory Leaks`).
* **`_safeNotifyListeners()`**: التحقق من عدم تدمير الكائن (`!_isDisposed`) قبل استدعاء `notifyListeners()` يمنع الأخطاء الشهيرة عند تنقل المستخدم بسرعة بين الشاشات.

## ⚡ نصائح الأداء والتحسين (Performance Tips)

:::tip المهام الثقيلة والمعالج (Isolates & compute)
تنفذ Dart كودها على خيل واحد (Single Thread). إذا كان لديك عملية فك ضغط بيانات JSON هائلة أو معالجة صور تستغرق أكثر من 16 مللي ثانية، استخدم `compute(parseJsonFunction, rawJsonString)`. تنقل هذه الدالة المعالجة إلى **Isolate** خارجي لمنع تجميد واجهة المستخدم.
:::

:::tip إلغاء الـ Stream Subscriptions دائماً
أي `StreamSubscription` تقوم بإنشائه داخل ViewModel أو State يجب إلغاؤه صراحة في دالة `dispose()`. عدم الإلغاء يترك الاستماع يعمل في الخلفية مستهلكاً الباطارية والرام.
:::

## 🐛 أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. مناداة notifyListeners بعد إغلاق الشاشة وتدمير الـ ViewModel
Future<void> loadData() async {
  var data = await repository.getData();
  notifyListeners(); // 💥 خطأ: إذا غادر المستخدم الشاشة أثناء جلب البيانات، ستستدعى الدالة على كائن ميت!
}

// ✅ الحل الصحيح: التثبت من حالة الكائن قبل الإخطار
Future<void> loadData() async {
  var data = await repository.getData();
  if (hasListeners) {
    notifyListeners();
  }
}


// ❌ 2. تنفيذ عمليات await المتتالية بدلاً من التوازية عند عدم وجود اعتمادية
var user = await fetchUser();       // يستغرق ثانية
var settings = await fetchSettings(); // يستغرق ثانية (الإجمالي 2 ثانية!)

// ✅ الحل الصحيح: استخدام Future.wait للتنفيذ الموازي
var results = await Future.wait([fetchUser(), fetchSettings()]); // يستغرق ثانية واحدة فقط!
```

## 🎤 أسئلة وأجوبة المقابلات الشخصية (Interview Q&A)

<details>
<summary><strong>س1: كيف تعمل حلقة الأحداث (Event Loop) في لغة Dart وما الفرق بين طابور Microtask وطابور Event؟</strong></summary>

لغة Dart تعمل بخيط واحد (Single Threaded). يدير هذا الخيط طابورين للأحداث:
1. **طابور Microtask Queue:** يمتلك أولوية قصوى ويحتوي على المهام الداخلية السريعة جداً الخاصة باللغة. لا ينتقل الخيط لتنفيذ أي حدث آخر حتى يفرغ هذا الطابور تماماً.
2. **طابور Event Queue:** يحتوي على الأحداث الخارجية مثل نقرات المستخدم، استجابات الشبكة، والمؤطرات الزمانية (`Timer`).

</details>

<details>
<summary><strong>س2: ما الفرق بين Single-Subscription Stream و Broadcast Stream؟</strong></summary>

- **Single-Subscription Stream:** يقبل مستمعاً واحداً فقط (`listen`) طوال فترة حياته، ويقوم بتخزين الأحداث حتى يبدأ المستمع المراقبة. يُستخدم عادة في عمليات قراءة الملفات أو طلبات الشبكة.
- **Broadcast Stream:** يقبل عدة مستمعين في وقت واحد، وتُبث الأحداث في التو واللحظة لكافة المستمعين الحاليين (مثل تحديثات الموقع المباشر GPS أو غرف المحادثة).

</details>

<details>
<summary><strong>س3: متى نستخدم Isolates بدلاً من Futures العادية؟</strong></summary>

نستخدم **Futures** للمهام غير التزامنية التي تنتظر مدخلات/مخرجات (I/O Bound) مثل طلبات الشبكة أو قاعدة البيانات. بينما نستخدم **Isolates** للمهام التي تستهلك المعالج بشكل مكثف (CPU Bound) مثل تشفير البيانات، معالجة الصور، أو معالجة مصفوفات ضخمة، وذلك لتنفيذها على نواة معالج مختلفة دون تعطيل الـ Main UI Thread.

</details>

<details>
<summary><strong>س4: ما فائدة الكلمات المفتاحية `async*` و `yield`؟</strong></summary>

تُستخدم الكلمة المفتاحية `async*` لتعريف دالة مولدة لتدفق بيانات مستمر (`Stream Generator`). وتُستخدم `yield` لإرسال وقذف قيمة جديدة إلى الـ Stream دون الخروج من الدالة، مما يسمح بضخ سلسلة متتالية من الأحداث عبر الزمن.

</details>

<ExerciseBox title="تمرين عملي - تطبيق العد التنازلي مع الـ Stream 🏋️">

قم بكتابة دالة مولدة لتدفق البيانات باسم `countdownStream(int startFrom)`:
1. تُرجع `Stream<int>`.
2. تقوم بإرسال الأرقام تنازلياً من `startFrom` حتى الوصول إلى `0` بفاصل ثانية واحدة بين كل حدث واستخدام `Future.delayed`.
3. استخدم الكلمات المفتاحية `async*` و `yield`.
4. في دالة `main()`: قم بالاستماع للـ Stream وطباعة النص `"Remaining seconds: $value"` واطبع `"Blast off! 🚀"` عند انتهاء التدفق.

</ExerciseBox>

<details>
<summary><strong>💡 اضغط هنا لرؤية الحل النموذجي المشروح بالتعليقات (Solution Code)</strong></summary>

```dart
import 'dart:async';

// 1. دالة مولدة لتدفق أعداد تنازلية مع async* و yield
Stream<int> countdownStream(int startFrom) async* {
  for (int i = startFrom; i >= 0; i--) {
    // الانتظار لمدة ثانية واحدة بين كل رقم
    await Future.delayed(const Duration(seconds: 1));
    // ضخ الرقم الحالي في الـ Stream
    yield i;
  }
}

void main() async {
  print('Starting countdown...');
  
  // الاستماع للـ Stream وطباعة الأرقام المنسابة
  await for (final value in countdownStream(5)) {
    print('Remaining seconds: $value');
  }

  print('Blast off! 🚀');
}
```

</details>

<SummaryBox title="ملخص الدرس 📌">

- تعتمد Dart على حلقة الأحداث (Event Loop) وإدارة طابوري `Microtask` و `Event` لمعالجة المهام دون تجميد واجهة المستخدم.
- الـ `Future` يُمثل قيمة مستقبلية واحدة، بينما يُمثل الـ `Stream` تدفقاً مستمراً من القيم عبر الزمن.
- استخدام `Future.wait` يسرّع أداء التطبيق بتشغيل طلبات الشبكة المستقبلية المستقلة بالتوازي.
- في معمارية **MVVM**، ينبغي دائماً تنظيف الاشتراكات في دالة `dispose()` والحذر من استدعاء `notifyListeners()` بعد مغادرة الشاشات.

</SummaryBox>
