# 2.6 النماذج والتحقق من صحة المدخلات (Forms & Validation)

إدارة استمارات الإدخال والتحقق من صحة البيانات هي جزء جوهري في تطبيقات التعامل مع المستخدمين.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. استخدام Form و `GlobalKey<FormState>`.
2. بناء حقول TextFormField مع واجهات التحقق (Validator).
3. استدعاء FormState.validate() وتفريغ الحقول.

---

## 1. مفتاح الفورم التجمعي (`GlobalKey<FormState>`)

### 📘 الشرح النظري
يُستخدم `GlobalKey<FormState>` لإدارة حالة النموذج ككل والتحقق من صحة جميع الحقول الفرعية بضغطة زر واحدة.

### 💻 التطبيق العملي
```dart
class FormStateExample {
  // مفتاح التحكم بالحالة العامة للاستمارة
  final formKey = `GlobalKey<FormState>`();
}
```

---

## 2. حقول النص المفحوصة (TextFormField & Validator)

### 📘 الشرح النظري
تتميز `TextFormField` بامتلاكها دالة `validator` تُرجع `null` إذا كان المدخل صالحاً، أو ترجع نص الخطأ التنبيهي إذا كان المدخل غير صالح.

### 💻 التطبيق العملي
```dart
TextFormField(
  decoration: const InputDecoration(labelText: 'Email'),
  validator: (value) {
    if (value == null || value.isEmpty) return 'البريد مطلوب';
    if (!value.contains('@')) return 'بريد غير صالح';
    return null; // مدخل صحيح 100%
  },
);
```

---

## 3. استدعاء التحقق والاعتماد (Form Validation Submission)

### 📘 الشرح النظري
عند استدعاء `_formKey.currentState!.validate()`. تقوم كافة الحقول المفحوصة بإظهار الرسائل التنبيهية التلقائية إذا كانت هناك أخطاء.

### 💻 التطبيق العملي
```dart
void submit(`GlobalKey<FormState>` key) {
  if (key.currentState!.validate()) {
    print('Form is 100% valid! Submitting to server...');
  }
}
```

---

## ⚡ نصائح الأداء والتحسين (Performance Tips)

:::tip تغليف الاستمارة بـ Form لتوفير مجهود الفحص
استدعاء دالة `validate()` واحدة يفحص كافة الحقول دفعة واحدة بدلاً من الفحص اليدوي المكرر.
:::

<summary><strong>س1: كيف تعمل دالة validator في TextFormField؟</strong></summary>

تُرجع null إذا كان المدخل سليماً، أو تُرجع String يحتوي على رسالة الخطأ المراد إظهارها تحت الحقل.

Widget buildForm(`GlobalKey<FormState>` key) {
  return Form(
    key: key,
    child: TextFormField(
      validator: (v) => (v == null || v.isEmpty) ? 'مطلوب' : null,
    ),
  );
}

<SummaryBox title="ملخص الدرس 📌">

- `GlobalKey<FormState>` يتحكم بحالة الفورم ككل.
- `validator` يُرجع `null` للمدخل الصحيح أو نص الخطأ.
- `validate()` يفحص كافة الحقول دفعة واحدة.

</SummaryBox>
