# 2.4 العروض القابلة للتمرير (Scrollable Views)

في تطبيقات الهاتف المحمول، يتم عرض القوائم والشبكات ذات العناصر المتعددة أو غير المحدودة باستخدام القوائم القابلة للتمرير بنمط التحميل الكسول (Lazy Loading).

---

## 🎯 أهداف الدرس (Learning Objectives)

1. استخدام SingleChildScrollView للشاشات القصيرة.
2. بناء القوائم الضخمة بواسطة ListView.builder لرفع الأداء.
3. عرض شبكات البيانات باستخدام GridView.builder.

---

## 1. التمرير المفرد (SingleChildScrollView)

### 📘 الشرح النظري
تُستخدم `SingleChildScrollView` عند رغبتك في جعل شاشة ثابتة (مثل فورم التسجيل) قابلة للتمرير على الشاشات الصغيرة لتجنب طفح المحتوى عند ظهور لوحة المفاتيح.

### 💻 التطبيق العملي
```dart
Widget buildScrollableForm() {
  return SingleChildScrollView(
    padding: const EdgeInsets.all(16),
    child: Column(
      children: const [
        TextField(decoration: InputDecoration(labelText: 'Email')),
        SizedBox(height: 16),
        TextField(decoration: InputDecoration(labelText: 'Password')),
      ],
    ),
  );
}
```

---

## 2. القوائم الكسولة (ListView.builder)

### 📘 الشرح النظري
تُعتبر `ListView.builder` الحل الأمثل للقوائم الطويلة. تقوم هذه الودجة بإنشاء العناصر المعروضة في الشاشة فقط (Lazy Rendering) وتتخلص من العناصر الخارجة من الذاكرة.

### 💻 التطبيق العملي
```dart
Widget buildLazyList(List<String> items) {
  return ListView.builder(
    itemCount: items.length,
    itemBuilder: (context, index) {
      // رندر العنصر الحالي فقط في الذاكرة
      return ListTile(
        title: Text(items[index]),
        leading: Icon(Icons.label),
      );
    },
  );
}
```

---

## 3. الشبكات التكعيبية (GridView.builder)

### 📘 الشرح النظري
تُستخدم `GridView.builder` لرص العناصر على شكل شبكة صفوف وأعمدة متناسقة (مثل متاجر المنتجات).

### 💻 التطبيق العملي
```dart
Widget buildProductGrid() {
  return GridView.builder(
    gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
      crossAxisCount: 2, // عمودين في كل صف
      crossAxisSpacing: 10,
      mainAxisSpacing: 10,
    ),
    itemCount: 20,
    itemBuilder: (context, index) {
      return Card(child: Center(child: Text('Item #$index')));
    },
  );
}
```

---

## ⚡ نصائح الأداء والتحسين (Performance Tips)

:::tip استخدام ListView.builder بدلاً من ListView()
استخدم `.builder` دائماً للقوائم التي تزيد عن 10 عناصر لمنع استهلاك الرام.
:::

## 🐛 أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. وضَع ListView عادية داخل SingleChildScrollView مما يدمر التحميل الكسول
SingleChildScrollView(child: ListView(children: [...]))

// ✅ الحل الصحيح
CustomScrollView(slivers: [SliverList(...)])

```

```dart
Widget buildList() {
  return ListView.builder(
    itemCount: 30,

    ),
  );
}
```
