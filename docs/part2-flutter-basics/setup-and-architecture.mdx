# 2.1 إعداد بيئة العمل والمعمارية الأساسية (Setup & Architecture)

في هذا الدرس، ستتعلم كيفية إعداد بيئة عمل Flutter بشكل احترافي، وفهم الهيكل الأساسي لمشروع Flutter، وكيفية ربط الدالة الرئيسية `main()` بالمكونات الجذرية للتطبيق مع اتّباع أفضل المعايير المعمارية.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. فهم دور الدالة الرئيسية `main()` والودجة الجذرية `MaterialApp`.
2. استيعاب دور `WidgetsFlutterBinding.ensureInitialized()`.
3. تنظيم الهيكل البرمجي الأساسي للمشروع ونقاط الانطلاق.

---

## 1. الدالة الرئيسية وحقن المحرك (Main Function & Binding)

### 📘 الشرح النظري
تبدأ حياة أي تطبيق Flutter من الدالة `main()`. قبل استدعاء `runApp()`. يُنصح دائماً باستدعاء `WidgetsFlutterBinding.ensureInitialized()` لضمان ربط محرك Flutter الاصطناعي (Flutter Engine) بأربطة الإطار الحركي قبل تنفيذ أي عمليات تهيئة أو اتصالات شبكية.

### 💻 التطبيق العملي
```dart
import 'package:flutter/material.dart';

void main() {
  // 1. التأكد من تهيئة أربطة المحرك الأساسية قبل تشغيل التطبيق
  WidgetsFlutterBinding.ensureInitialized();
  
  // 2. تشغيل الودجة الجذرية للتطبيق
  runApp(const RootApp());
}
```

---

## 2. الودجة الجذرية للمظهر والشاشات (MaterialApp Configuration)

### 📘 الشرح النظري
تُعتبر `MaterialApp` الودجة المسؤولة عن توفير السمات العامة (Themes)، موجه الصفحات (Router)، ونظام النصوص والتنقل لجميع الشاشات التابعة لها في تطبيقك.

### 💻 التطبيق العملي
```dart
class RootApp extends StatelessWidget {
  const RootApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter Architecture Baseline',
      debugShowCheckedModeBanner: false, // إخفاء شارة الديباج
      theme: ThemeData.dark(useMaterial3: true), // تفعيل Material 3
      home: const HomeScreen(),
    );
  }
}
```

---

## 3. الهيكل الأساسي للشاشة (Scaffold Baseline)

### 📘 الشرح النظري
تُوفر ودجة `Scaffold` الهيكل البصري القياسي لشاشات Material Design، مثل شريط العنوان (`AppBar`)، منطقة المحتوى (`body`)، وزر العمليات العائم (`FloatingActionButton`).

### 💻 التطبيق العملي
```dart
class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Architecture Baseline'),
        centerTitle: true,
      ),
      body: const Center(
        child: Text('Flutter Architecture Ready! 🚀'),
      ),
    );
  }
}
```

## ⚡ نصائح الأداء والتحسين (Performance Tips)

:::tip تجنب وضع العمليات الثقيلة داخل main()
احرص على ألا تحتوي الدالة `main()` على حسابات معقدة أو اتصالات شبكية بطيئة تتجاوز ثوانٍ معدودة، حتى لا يتعطل ظهور شاشة البدء (Splash Screen) أمام المستخدم.
:::

## 🐛 أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. نسيان ensureInitialized قبل تهيئة المكتبات
void main() {
  // 💥 خطأ: استخدام خدمات محلية قبل تهيئة الأربطة يؤدي لكراش!
  runApp(const MyApp());
}

// ✅ الحل الصحيح
void main() {
  WidgetsFlutterBinding.ensureInitialized();
  runApp(const MyApp());
}
```
