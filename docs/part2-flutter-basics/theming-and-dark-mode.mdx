# 2.7 السمات والوضع الداكن (Theming & Dark Mode)

تأمين تجربة مستخدم مبهرة يتطلب توفير نسق ألوان جذاب ودعم كامل للوضع الفاتح (Light Mode) والوضع الداكن (Dark Mode). يتيح نظام `ThemeData` و `ColorScheme` في Flutter إمكانية بناء سمات موحدة ومرنة.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. بناء سمات متناسقة باستخدام `ThemeData` و Material 3 `ColorScheme`.
2. تصميم ثيم فاتح وثيم داكن مخصص يرتكز على اللون الفيروزي/الرئيسي `#0175C2`.
3. إنشاء `ThemeViewModel` لإدارة السمة والتبديل الديناميكي بين الوضعين.
4. الوصول إلى سمات الألوان والنصوص داخل الـ Widgets بأسلوب نظيف عبر `Theme.of(context)`.

---

## 📘 الشرح النظري (Theoretical Explanation)

في Flutter، يُعتبر نظام `ThemeData` المرجع القياسي لجميع الودجات الفرعية:

* **`Theme.of(context).colorScheme.primary`**: للحصول على اللون الرئيسي.
* **`Theme.of(context).textTheme.headlineMedium`**: للحصول على تنسيق الخطوط الموحد.

بفضل معمارية MVVM، نقوم بتخزين وضع السمة الحالية (`ThemeMode.light` أو `ThemeMode.dark`) في ViewModel مخصص يمتد من `ChangeNotifier`.

---

## 💻 التطبيق المعماري (MVVM & Clean Code)

نقم بإنشاء السمة المركزية في `lib/core/theme/app_theme.dart` مع الـ ViewModel المخصص للسمة في `lib/presentation/viewmodels/theme_viewmodel.dart`.

```dart
// ==========================================
// File: lib/core/theme/app_theme.dart
// Description: إعدادات السمات الأنيقة للوضع الفاتح والداكن
// Architecture Layer: Core Theme
// ==========================================

import 'package:flutter/material.dart';

class AppTheme {
  static const Color primaryBlue = Color(0xFF0175C2);

  /// السمة الفاتحة (Light Theme)
  static ThemeData get lightTheme {
    return ThemeData(
      useMaterial3: true,
      brightness: Brightness.light,
      colorScheme: ColorScheme.fromSeed(
        seedColor: primaryBlue,
        brightness: Brightness.light,
      ),
      scaffoldBackgroundColor: const Color(0xFFF8FAFC),
      appBarTheme: const AppBarTheme(
        centerTitle: true,
        elevation: 0,
        backgroundColor: Colors.white,
        foregroundColor: Color(0xFF0F172A),
      ),
    );
  }

  /// السمة الداكنة (Dark Theme)
  static ThemeData get darkTheme {
    return ThemeData(
      useMaterial3: true,
      brightness: Brightness.dark,
      colorScheme: ColorScheme.fromSeed(
        seedColor: primaryBlue,
        brightness: Brightness.dark,
      ),
      scaffoldBackgroundColor: const Color(0xFF0F172A),
      appBarTheme: const AppBarTheme(
        centerTitle: true,
        elevation: 0,
        backgroundColor: Color(0xFF1E293B),
        foregroundColor: Colors.white,
      ),
    );
  }
}

// ==========================================
// File: lib/presentation/viewmodels/theme_viewmodel.dart
// Description: ViewModel يتولى التبديل الديناميكي بين وضع الثيم
// Architecture Layer: Presentation (ViewModel)
// ==========================================

import 'package:flutter/material.dart';

class ThemeViewModel extends ChangeNotifier {
  ThemeMode _themeMode = ThemeMode.system;

  ThemeMode get themeMode => _themeMode;

  bool get isDarkMode => _themeMode == ThemeMode.dark;

  void toggleTheme(bool isDark) {
    _themeMode = isDark ? ThemeMode.dark : ThemeMode.light;
    notifyListeners();
  }
}
```

<SummaryBox title="خلاصة الدرس 📌">

- يجب دائماً استخدام `Theme.of(context)` داخل الـ Widgets بدلاً من كتابة الألوان الثابتة يدوياً لضمان التوافق التلقائي مع الوضع الداكن.
- تتيح معمارية **MVVM** إمكانية تغيير وضع السمة وتخزين التفضيلات بسلاسة دون تعقيد الـ UI.
- توفر حزمة Material 3 تحكماً متطوراً بالألوان التكيفية التلقائية.

</SummaryBox>
