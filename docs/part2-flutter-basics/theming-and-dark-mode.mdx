# 2.7 الثيمات والوضع الداكن (Theming & Dark Mode)

إدارة الهوية البصرية وتوفير المظهر الداكن (Dark Mode) يمنح تطبيقك طابعاً احترافياً ويوفر استهلاك البطارية.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. تحديد ThemeData موحد باستخدام Material 3.
2. تخصيص الألوان والخطوط المركزية عبر ColorScheme.
3. دعم التبديل السلس بين المظهر الفاتح والداكن.

---

## 1. تحديد المظهر العام (ThemeData & ColorScheme)

### 📘 الشرح النظري
نستخدم `ThemeData` لتعريف الهوية البصرية المركزية للتطبيق بأكمله لمنع كتابة الألوان يدوياً في كل ودجة.

### 💻 التطبيق العملي
```dart
class AppTheme {
  static final darkTheme = ThemeData(
    useMaterial3: true,
    colorScheme: ColorScheme.fromSeed(
      seedColor: Colors.skyBlue,
      brightness: Brightness.dark,
    ),
    scaffoldBackgroundColor: const Color(0xFF060C18),
  );
}
```

---

## 2. الوصول للألوان داخل الواجهة (Theme.of(context))

### 📘 الشرح النظري
استخدم `Theme.of(context)` لقراءة الألوان العامة بدلاً من الألوان الثابتة لتستجيب الواجهة تلقائياً عند تغيير المظهر.

### 💻 التطبيق العملي
```dart
Widget buildStyledText(BuildContext context) {
  return Text(
    'Dynamic Color Text',
    style: TextStyle(color: Theme.of(context).colorScheme.primary),
  );
}
```

---

## ⚡ نصائح الأداء والتحسين (Performance Tips)

:::tip الاعتماد المباشر على Theme.of(context)
يضمن تغير ألوان التطبيق بأكمله فوراً عند تبديل الوضع الداكن دون إعادة كتابة الأكواد.
:::

---

## 🐛 أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. كتابة ألوان ثابتة هارد كود داخل الودجات
Text('Hi', style: TextStyle(color: Colors.black))

// ✅ الحل الصحيح
Text('Hi', style: TextStyle(color: Theme.of(context).colorScheme.onBackground))

```
