# 2.5 التنقل وإدارة المسارات (go_router Navigation)

يُعتبر إطار `go_router` الحل القياسي الموصى به من فريق Flutter لإدارة التوجيه المساري (Declarative Routing) لدعم التمرير الديناميكي والويب.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. تهيئة كائن GoRouter وتحديد المسارات.
2. تمرير المعاملات الديناميكية (Path Parameters).
3. إدارة المسارات المجهولة عبر errorBuilder.

---

## 1. إعداد كائن التوجيه (GoRouter Configuration)

### 📘 الشرح النظري
يقوم كائن `GoRouter` بتعريف قائمة المسارات (`routes`) والصفحة الرئيسية المبدئية (`initialLocation`).

### 💻 التطبيق العملي
```dart
final GoRouter router = GoRouter(
  initialLocation: '/',
  routes: [
    GoRoute(
      path: '/',
      builder: (context, state) => const HomeScreen(),
    ),
  ],
);
```

---

## 2. المسارات الديناميكية وتمرير البيانات (Path Parameters)

### 📘 الشرح النظري
تُستخدم النقطتان `:param` لتعريف متغيرات في عنوان الرابط (URL) وقراءتها بسهولة من كائن `state.pathParameters`.

### 💻 التطبيق العملي
```dart
GoRoute(
  path: '/details/:id',
  builder: (context, state) {
    final id = state.pathParameters['id'] ?? '0';
    return DetailsScreen(id: id);
  },
);
```

---

## 3. أوامر التنقل المباشر (context.go vs context.push)

### 📘 الشرح النظري
استخدم `context.go()` للتنقل المعرف الذي يغير عنوان الرابط، واستخدم `context.push()` لإضافة صفحة فوق الـ Stack.

### 💻 التطبيق العملي
```dart
void navigateToDetails(BuildContext context, String productId) {
  // التنقل المعرف السلس
  context.go('/details/$productId');
}
```

---

## ⚡ نصائح الأداء والتحسين (Performance Tips)

:::tip استخدام context.go() للتنقلات الرئيسية
يضمن `context.go` تحديث الرابط على الويب ومتوافق مع النمط المعرف.
:::

```dart
// ❌ 1. استخدام Navigator 1.0 القديم في مشاريع كبيرة
Navigator.push(context, MaterialPageRoute(...))

// ✅ الحل الصحيح
context.go('/details/123')

```

## 🎤 أسئلة وأجوبة المقابلات (Interview Q&A)

<details>
<summary><strong>س1: ما الفرق بين context.go و context.push في go_router؟</strong></summary>

`context.go` تنقل معرف يغير شجرة المسارات، بينما `context.push` تضيف صفحة فوق الـ Stack الحالية.

</details>
