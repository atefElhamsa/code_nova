# 2.3 ودجات التنسيق والتخطيط (Layout Widgets)

إتقان التنسيق في Flutter يعتمد على فهم كيفية تنظيم العناصر عمودياً وإفقياً، والتحكم في المساحات والتراكمات باستخدام `Column`, `Row`, `Expanded`, `Flexible`, و `Stack`.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. التنظيم العمودي والأفقي باستخدام `Column` و `Row`.
2. معالجة طفح المحتوى (Overflow) بواسطة `Expanded` و `Flexible`.
3. تجميع العناصر المتراكمة فوق بعضها بـ `Stack` و `Positioned`.

---

## 1. التنسيق العمودي والأفقي (Column & Row)

### 📘 الشرح النظري
تُستخدم `Column` لرص العناصر رأسباً، وتُستخدم `Row` لرص العناصر أفقياً. يتم التحكم بالرص عبر المحور الرئيسي (`mainAxisAlignment`) والمحور الفرعي (`crossAxisAlignment`).

### 💻 التطبيق العملي
```dart
import 'package:flutter/material.dart';

Widget buildUserRow() {
  return Row(
    mainAxisAlignment: MainAxisAlignment.spaceBetween, // محاذاة الأطراف
    crossAxisAlignment: CrossAlignment.center,
    children: const [
      Icon(Icons.person),
      Text('Ahmed Ali'),
      Icon(Icons.arrow_forward_ios, size: 16),
    ],
  );
}
```

---

## 2. إدارة المساحات المتبقية (Expanded & Flexible)

### 📘 الشرح النظري
تُستخدم `Expanded` لإجبار الودجة الابن على ملء كافة المساحة المتبقية داخل `Row` أو `Column` لمنع خطأ طفح المحتوى الأصفر الشهير (Yellow Overflow Strip).

### 💻 التطبيق العملي
```dart
Widget buildFlexibleTitle() {
  return Row(
    children: const [
      Icon(Icons.title),
      SizedBox(width: 8),
      Expanded(
        // تضمن تمدد النص وتدفقه بمرونة دون الخروج عن حدود الشاشة
        child: Text('Very long product title that wraps safely inside row'),
      ),
    ],
  );
}
```

---

## 3. التراكم فوق البصريات (Stack & Positioned)

### 📘 الشرح النظري
تُتيح ودجة `Stack` وضع العناصر فوق بعضها البعض على المحور Z. ونستخدم `Positioned` لتحديد إحداثيات موقع الودجة بدقة (أعلى، أسفل، يمين، يسار).

### 💻 التطبيق العملي
```dart
Widget buildBadgeImage() {
  return Stack(
    children: [
      Container(width: 100, height: 100, color: Colors.blueGrey),
      Positioned(
        top: 4,
        right: 4,
        child: Container(
          padding: const EdgeInsets.all(4),
          color: Colors.red,
          child: const Text('NEW', style: TextStyle(fontSize: 10, color: Colors.white)),
        ),
      ),
    ],
  );
}
```

---

## ⚡ نصائح الأداء والتحسين (Performance Tips)

:::tip استخدام SizedBox بدلاً من Container للمساحات
استخدم `const SizedBox(width: 8)` للفواصل المكانية الخالية بدلاً من `Container`، لأن `SizedBox` أخف وزناً بكثير على الذاكرة والرسم.
:::

## 🐛 أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. وضع ListView غير محددة الحجم داخل Column بدون Expanded
Column(
  children: [
    // 💥 خطأ: يسبب Unbounded Height Error!
    ListView(children: [ ... ]),
  ],
)

// ✅ الحل الصحيح
Column(
  children: [
    Expanded(child: ListView(children: [ ... ])),
  ],
)
```

## 🎤 أسئلة وأجوبة المقابلات (Interview Q&A)

<details>
<summary><strong>س1: ما الفرق بين Expanded و Flexible؟</strong></summary>

- **Expanded:** تُجبر الودجة الابن على شغل كامل المساحة المتبقية إجبارياً.
- **Flexible:** تتيح للودجة شغل مساحة تصل كحد أقصى للمساحة المتبقية دون إجبارها على ملئها بالكامل إذا كان حجمها أصغر.

</details>

صمم كارت منتج يحتوي على صورة بعلامة خصم متداخلة فوقها (`Stack`) وعنوان وسعر جنبًا إلى جنب (`Row` و `Expanded`).

<details>
<summary><strong>💡 اضغط هنا لرؤية الحل النموذجي المشروح بالتعليقات (Solution Code)</strong></summary>

```dart
import 'package:flutter/material.dart';

Widget buildProductCard() {
  return Container(
    width: 200,
    padding: const EdgeInsets.all(8),
    color: Colors.black12,
    child: Column(
      mainAxisSize: MainAxisSize.min,
      children: [
        Stack(
          children: [
            Container(height: 100, color: Colors.grey),
            Positioned(top: 4, right: 4, child: Text('SALE', style: TextStyle(color: Colors.red))),
          ],
        ),
        Row(
          children: const [
            Expanded(child: Text('Item Name', overflow: TextOverflow.ellipsis)),
            Text('$99'),
          ],
        ),
      ],
    ),
  );
}
```

</details>

<SummaryBox title="ملخص الدرس 📌">

- `Column` و `Row` هما الركيزتان الأساسيتان للتخطيط.
- `Expanded` تُعالج مشاكل طفح المحتوى.
- `Stack` و `Positioned` للتراكم وإضافة الشارات المتموضعة.

</SummaryBox>
