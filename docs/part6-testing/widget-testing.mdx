# 6.2 اختبارات الودجات واختبار السلوك البصري (Widget Testing)

تُمكّنك اختبارات الودجات من التثبت من ظهور العناصر البصرية، الاستجابة لنقرات الأزرار، وإظهار نصوص الأخطاء دون فتح محاكي.

---

##  أهداف الدرس (Learning Objectives)

1. استخدام testWidgets و WidgetTester.
2. ضخ الودجات بواسطة pumpWidget.
3. البحث عن العناصر عبر finders و expect.

---

## 1. ضخ الودجة والبحث في الشجرة (pumpWidget & Finders)

### 📘 الشرح النظري
تُغلف الودجة المراد اختبارها بـ `MaterialApp` وتُضخ باستخدام `tester.pumpWidget()` ثم نستخدم `find.text()` للبحث.

### 💻 التطبيق العملي
```dart
testWidgets('Should display title text', (WidgetTester tester) async {
  await tester.pumpWidget(
    const MaterialApp(
      home: Scaffold(body: Text('TaskFlow Pro')),
    ),
  );

  expect(find.text('TaskFlow Pro'), findsOneWidget);
});
```

:::

##  أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. نسيان تغليف الودجة الاختيارية بـ MaterialApp أو Directionality
await tester.pumpWidget(const MyCustomButton()); // 💥 كراش لغياب التغطية!

// ✅ الحل الصحيح
await tester.pumpWidget(MaterialApp(home: Scaffold(body: MyCustomButton())));

```

##  أسئلة وأجوبة المقابلات (Interview Q&A)

<details>
<summary><strong>س1: ما فائدة tester.pump() و tester.pumpAndSettle()؟</strong></summary>

`pump()` تقوم بإعادة رسم إطار واحد، بينما `pumpAndSettle()` تنتظر انتهاء كافة الأنيميشن والعمليات المؤجلة.

</details>
