# 6.1 الاختبارات الأحادية (Unit Testing)

تضمن الاختبارات الأحادية صحة وسلامة المنطق البرمجي للـ ViewModels والـ Repositories مع كل تعديل كود جديد.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. فهم هيكل الاختبار (Arrange, Act, Assert).
2. كتابة اختبارات لـ ViewModel.
3. استخدام expect و equals.

---

## 1. هيكل الاختبار الأحادي (Triple-A Pattern)

### 📘 الشرح النظري
يتكون كل اختبار من 3 خطوات: Arrange (تجهيز التبعيات)، Act (تنفيذ الدالة)، و Assert (التأكد من النتيجة).

### 💻 التطبيق العملي
```dart
import 'package:flutter_test/flutter_test.dart';

void main() {
  test('Counter increment test', () {
    // 1. Arrange
    final counter = Counter();
    
    // 2. Act
    counter.increment();
    
    // 3. Assert
    expect(counter.value, equals(1));
  });
}
```

---

## ⚡ نصائح الأداء والتحسين (Performance Tips)

:::tip سرعة تشغيل الاختبارات الأحادية
الاختبارات الأحادية تنفذ على المعالج مباشرة دون فتح محاكي وتوفر وقت الفحص اليدوي.
:::
