# 5.4 تسلسل البيانات تلقائياً (JSON Serialization with json_serializable)

التحليل اليدوي لبيانات JSON المعقدة آتية من السيرفر قد يسبب أخطاء كتابية كثيرة وصعوبة في التتبع. تتيح حزمتا `json_serializable` و `build_runner` توليد دوال `fromJson` و `toJson` تلقائياً وبكفاءة صارمة.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. فهم فوائد التوليد التلقائي لدوّال تسلسل البيانات مقارنة بالتحليل اليدوي.
2. إضافة وتكوين حزم `json_annotation`, `json_serializable`, و `build_runner`.
3. استخدام التلميحات البرمجية `@JsonSerializable()` و `@JsonKey(name: '...')`.
4. تشغيل أمر توليد الكود التلقائي وإدارة ملفات `.g.dart`.

---

## 📘 الشرح النظري (Theoretical Explanation)

تتيح حزمة `json_serializable` قراءة الفئة وتوليد كود دقيق وفعال يتعامل مع حقول الـ JSON بالأنواع الصحيحة وإعادة تسميتها إذا اختلفت تسميات السيرفر عن قواعد تسمية Dart.

### الأمر الأساسي لتوليد الكود:
```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

---

## 💻 التطبيق المعماري (MVVM & Clean Code)

توليد نموذج مستخدم كامل مع ربط ملف التوليد التلقائي `.g.dart`.

```dart
// ==========================================
// File: lib/data/models/api_user_model.dart
// Description: نموذج بيانات يتولى التحليل التلقائي بـ json_serializable
// Architecture Layer: Data (Model DTO)
// ==========================================

import 'package:json_annotation/json_annotation.dart';

// 1. إخبار Dart بأن هذا الملف مرتبط بملف الكود المولد
part 'api_user_model.g.dart';

@JsonSerializable(explicitToJson: true)
class ApiUserModel {
  final String id;

  // إعادة تعيين اسم المفتاح إذا كان بالسيرفر snake_case
  @JsonKey(name: 'first_name')
  final String firstName;

  @JsonKey(name: 'is_active', defaultValue: true)
  final bool isActive;

  const ApiUserModel({
    required this.id,
    required this.firstName,
    required this.isActive,
  });

  /// 2. ربط دالة fromJson بالدالة المولدة تلقائياً
  factory ApiUserModel.fromJson(Map<String, dynamic> json) =>
      _$ApiUserModelFromJson(json);

  /// 3. ربط دالة toJson بالدالة المولدة تلقائياً
  Map<String, dynamic> toJson() => _$ApiUserModelToJson(this);
}
```

<SummaryBox title="خلاصة الدرس 📌">

- استخدام التوليد التلقائي لـ JSON تلغي الأخطاء البشرية الإملائية عند مطابقة المفاتيح.
- التلميح `@JsonKey` يسمح بالحفاظ على تسمية `camelCase` القياسية في Dart دون التأثر بأسماء `snake_case` من السيرفر.
- ربط ملفات `part '*.g.dart'` يمنح مترجم Dart الوصول للحلول المولدة بنظافة عالية.

</SummaryBox>
