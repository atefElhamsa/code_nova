# 5.4 التوليد التلقائي لفك واستخراج JSON (json_serializable)

استخدام التوليد التلقائي عبر `json_serializable` و `build_runner` يلغي الأخطاء الإملائية اليدوية عند فك بيانات الشبكة.

---

##  أهداف الدرس (Learning Objectives)

1. إضافة حزم json_annotation و build_runner.
2. استخدام التلميحات @JsonSerializable و @JsonKey.
3. توليد ملفات .g.dart المساعدة.

---

## 1. نماذج التوليد التلقائي (@JsonSerializable)

### 📘 الشرح النظري
نضيف التلميح `@JsonSerializable()` ونعرف الجزء المولّد `part 'file_name.g.dart';`.

### 💻 التطبيق العملي
```dart
import 'package:json_annotation/json_annotation.dart';
part 'user_model.g.dart';

@JsonSerializable()
class UserModel {
  @JsonKey(name: 'user_id')
  final String id;
  final String name;

  UserModel({required this.id, required this.name});

  factory UserModel.fromJson(Map<String, dynamic> json) => _$UserModelFromJson(json);
  Map<String, dynamic> toJson() => _$UserModelToJson(this);
}
```

:::tip أمر التوليد المستمر
استخدم `dart run build_runner watch` لتوليد الأكواد تلقائياً فور حفظ الملفات.
:::

##  أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. نسيان جزء part 'file.g.dart' في أعلى الملف
@JsonSerializable() class User {} // بدون part

// ✅ الحل الصحيح
part 'user.g.dart'; @JsonSerializable() class User {}

```
