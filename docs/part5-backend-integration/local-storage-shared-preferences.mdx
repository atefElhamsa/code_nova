# 5.5 التخزين المحلي باستخدام SharedPreferences

تُستخدم مكتبة `shared_preferences` لتخزين البيانات البسيطة (مثل توكن المصادقة، الإعدادات، والمظهر) على جهاز المستخدم.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. تهيئة كائن SharedPreferences.
2. حفظ وقراءة البيانات الأساسية (String, bool, int).
3. تغليف التخزين في خدمة مستقلة LocalStorageService.

---

## 1. خدمة التخزين المغلفة (LocalStorageService)

### 📘 الشرح النظري
نغلف مكتبة SharedPreferences داخل فئة مستقلة نضعها في مجلد `core/storage` ونحقنها عبر `get_it`.

### 💻 التطبيق العملي
```dart
class LocalStorageService {
  final SharedPreferences _prefs;
  LocalStorageService(this._prefs);

  Future<bool> saveAuthToken(String token) async {
    return await _prefs.setString('auth_token', token);
  }

  String? getAuthToken() {
    return _prefs.getString('auth_token');
  }
}
```

---

## ⚡ نصائح الأداء والتحسين (Performance Tips)

:::tip تسجيل النسخة الأحادية Singleton في get_it
قم باستدعاء `SharedPreferences.getInstance()` مرة واحدة فقط أثناء بداية التشغيل.
:::

---

## 🐛 أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. محاولة حفظ كائنات معقدة مباشرة دون تحويلها لـ JSON String
_prefs.setObject('user', userModel); // غير مدعوم مباشرة!

// ✅ الحل الصحيح
_prefs.setString('user', jsonEncode(userModel.toJson()));

```
