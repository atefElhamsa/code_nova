# 5.2 نمط المستودع وإدارة المصادر (Repository Pattern)

نمط المستودع (Repository Pattern) يُشكل وسيطاً ذكياً بين مصادر البيانات المختلفة (السيرفر والتخزين المحلي) وطبقة العرض.

---

##  أهداف الدرس (Learning Objectives)

1. فصل Remote Datasource عن Local Datasource.
2. تطبيق استراتيجية التخزين المؤقت (Caching Strategy).
3. توحيد العقد البرمجي للبيانات.

---

## 1. استراتيجية التخزين المؤقت (Caching Strategy)

### 📘 الشرح النظري
يقوم المستودع بجلب البيانات من السيرفر، وحفظها محلياً في الرام أو SharedPreferences، واستعادتها فوراً عند انقطاع الإنترنت.

### 💻 التطبيق العملي
```dart
class ProductRepositoryImpl {
  final RemoteDs remote;
  final LocalDs local;
  ProductRepositoryImpl(this.remote, this.local);

  Future<List<String>> getProducts() async {
    try {
      final list = await remote.fetch();
      await local.save(list); // التخزين الكسولي
      return list;
    } catch (_) {
      return await local.getSaved(); // القراءة المحلية عند انقطاع الشبكة
    }
  }
}
```

---

##  نصائح الأداء والتحسين (Performance Tips)

:::tip السرعة والعمل بدون إنترنت (Offline First)
الـ Caching المحلي يجعل التطبيق يفتح فوراً ويعرض البيانات المحفوظة مسبقاً.
:::
