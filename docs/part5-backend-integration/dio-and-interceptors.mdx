# 5.1 الاتصال الشبكي المتقدم بـ Dio & Interceptors

مكتبة `dio` هي الخيار الاحترافي الأول لإجراء اتصالات HTTP المعقدة وإضافة الـ Interceptors لحقن توكنات المصادقة وطباعة السجلات.

---

##  أهداف الدرس (Learning Objectives)

1. إعداد كائن Dio وضبط BaseOptions.
2. إنشاء Interceptor لحقن التوكن تلقائياً.
3. معالجة مهلة الاتصال والأخطاء.

---

## 1. إعداد كائن Dio الأساسي

### 📘 الشرح النظري
نحدد `BaseOptions` لضبط عنوان السيرفر الرئيسي (`baseUrl`) ومواعيد مهلة الاتصال (`connectTimeout`).

### 💻 التطبيق العملي
```dart
final dio = Dio(
  BaseOptions(
    baseUrl: 'https://api.example.com',
    connectTimeout: const Duration(seconds: 5),
    receiveTimeout: const Duration(seconds: 5),
  ),
);
```

---

## 2. معترضات الطلبات (Dio Interceptors)

### 📘 الشرح النظري
تُستخدم `Interceptor` لاقتاص كل طلب شبكي قبل إرساله لحقن التوكن في الهيدر (`Authorization Header`) تلقائياً.

### 💻 التطبيق العملي
```dart
class AuthInterceptor extends Interceptor {
  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler) {
    options.headers['Authorization'] = 'Bearer MY_TOKEN';
    super.onRequest(options, handler);
  }
}
```

---

##  نصائح الأداء والتحسين (Performance Tips)

:::tip إضافة Interceptor واحد لكل المهام الشبكية
يغنيك عن كتابة كود إرسال التوكن في كل طلب شبكي على حدة.
:::
