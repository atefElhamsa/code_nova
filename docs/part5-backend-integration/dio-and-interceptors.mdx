# 5.1 الاتصالات الشبكية المتقدمة (Networking with Dio & Interceptors)

عند بناء تطبيق Flutter يدعم خدمات خلفية (Backend APIs)، تكون مكتبة **Dio** الخيار المفضل والقياسي بين المطورين المحترفين لما توفره من إمكانيات متقدمة مثل إعداد مهلة الاتصال (Timeouts)، اعتراض الطلبات والترويسات عبر **Interceptors**، وإدارة التشفير وإلغاء الطلبات.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. فهم مزايا مكتبة Dio مقارنة بالمكتبة الأساسية `http`.
2. إعداد العميل الشبكي الموحد `DioClient` بإعدادات `BaseOptions`.
3. كتابة **Interceptors** مخصصة لطباعة السجلات (Logging) وإرفاق توكن المصادقة (Auth Token).
4. تطبيق عزل إعدادات الاتصال داخل الطبقة القياسية `core/network/`.

---

## 📘 الشرح النظري (Theoretical Explanation)

### ما هو الـ Interceptor (معترض الطلبات)؟
الـ Interceptor هو وسيط برمجي يتم اعتراض الطلب أو الاستجابة أو الخطأ الشبكي من خلاله **قبل** وصوله للـ Repository أو الخادم.

يستفاد منه في:
* إضافة `Authorization: Bearer <token>` لكل الطلبات تلقائياً.
* طباعة البيانات المدخلة والمخرجة في الـ Terminal لتسهيل التتبع والـ Debugging.
* تحديث التوكن تلقائياً (Refresh Token) عند انتهاء صلاحيته (401 Unauthorized).

---

## 💻 التطبيق المعماري (MVVM & Clean Code)

إعداد عميل Dio المركزي مع الترويسات والـ Interceptors داخل `lib/core/network/dio_client.dart`.

```dart
// ==========================================
// File: lib/core/network/dio_client.dart
// Description: العميل الشبكي الرئيسي المعتمد على Dio
// Architecture Layer: Core Network
// ==========================================

import 'package:dio/dio.dart';

class DioClient {
  late final Dio _dio;

  DioClient() {
    _dio = Dio(
      BaseOptions(
        baseUrl: 'https://api.example.com/v1/',
        connectTimeout: const Duration(seconds: 10),
        receiveTimeout: const Duration(seconds: 10),
        headers: {
          'Content-Type': 'application/json',
          'Accept': 'application/json',
        },
      ),
    );

    // إضافة معترضات الطلبات
    _dio.interceptors.add(
      InterceptorsWrapper(
        onRequest: (options, handler) {
          // محاكاة إرفاق توكن مصادقة حقيقي
          const token = 'YOUR_SECURE_AUTH_TOKEN';
          options.headers['Authorization'] = 'Bearer $token';
          print('🌐 [GET/POST Request] -> Path: ${options.path}');
          return handler.next(options);
        },
        onResponse: (response, handler) {
          print('✅ [API Response Success] -> Status: ${response.statusCode}');
          return handler.next(response);
        },
        onError: (DioException error, handler) {
          print('❌ [API Error] -> Message: ${error.message}');
          return handler.next(error);
        },
      ),
    );
  }

  Dio get instance => _dio;
}
```
