# 5.3 معالجة الأخطاء وكائنات الفشل (Error Handling & Failures)

تحويل استثناءات dio المعقدة إلى كائنات فشل (Failure Objects) واضحة المعالم يرفع من استقرار التطبيق وسلاسة التنبيهات.

---

##  أهداف الدرس (Learning Objectives)

1. تعريف التسلسل الهرمي لكائنات Failure.
2. تحويل DioException إلى ServerFailure.
3. عرض التنبيهات المترجمة للمستخدم.

---

## 1. كائنات الفشل المعمارية (Failure Hierarchy)

### 📘 الشرح النظري
نعرف فئة مجردة `Failure` ترث منها أنواع الفشل المحددة (ServerFailure, NetworkFailure, CacheFailure).

### 💻 التطبيق العملي
```dart
abstract class Failure {
  final String message;
  const Failure(this.message);
}

class ServerFailure extends Failure {
  const ServerFailure(super.message);
}
```

---

## 2. تحليل استثناءات Dio (DioException Parsing)

### 📘 الشرح النظري
نحفظ دالة مصنعية تحلل رمز الاستجابة (`statusCode`) وترجمته لرسالة مفهومة للمستخدم.

### 💻 التطبيق العملي
```dart
ServerFailure parseDioError(DioException error) {
  if (error.type == DioExceptionType.connectionTimeout) {
    return const ServerFailure('انتهت مهلة الاتصال بالشبكة');
  }
  final code = error.response?.statusCode;
  if (code == 401) return const ServerFailure('غير مصرح لك بالدخول');
  return ServerFailure('خطأ سيرفر رمز: $code');
}
```

##  نصائح الأداء والتحسين (Performance Tips)

```dart
// ❌ 1. إظهار نصوص الاستثناءات الإنجليزية الخام للمستخدم مثل DioError [bad response]
```
