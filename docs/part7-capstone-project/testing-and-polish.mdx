# 7.5 الفحص الشامل وتوليد النسخة النهائية (Testing & Release)

الفحص الختامي الشامل وإجراء اختبارات التجمع وتوليد النسخة الإنتاجية المجهزة للتسليم.

---

##  أهداف الدرس (Learning Objectives)

1. تشغيل كافة الاختبارات عبر flutter test.
2. توليد النسخة النهائية APK و Web.
3. المراجعة النهائية لمعايير Clean Architecture.

---

## 1. أوامر التجميع والإنتاج النهائي

### 📘 الشرح النظري
نستخدم أوامر Flutter CLI لبناء الحزم الإنتاجية المعالجة ضد الضغط والهندسة العكسية.

### 💻 التطبيق العملي
```dart
/*
# تشغيل كامل بنك الاختبارات
flutter test

# بناء تطبيق الإنتاج لأندرويد
flutter build apk --release

# بناء نسخة الويب
flutter build web --release
*/
```
