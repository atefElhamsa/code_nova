# 7.3 مشروع Capstone: طبقة العرض والـ ViewModel (TaskListViewModel)

في الجلسة الثالثة، سنبني **الـ ViewModel الرئيسي لميزة المهام (TaskListViewModel)**، والذي سيتولى إدارة جميع حالات الشاشة (Loading, Success, Failure)، تصفية القوائم (All, Active, Completed)، ومعالجة إضافة وتعديل المهام.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. بناء `TaskListViewModel` الممتد من `ChangeNotifier`.
2. تزويد الواجهة بالقوائم المصفاة بناءً على الفلتر الحالي النشط.
3. معالجة العمليات غير التزامنية مع إرسال إخطارات التحديث `notifyListeners()`.
4. التحقق من سلامة البيانات المدخلة قبل تسليمها إلى المستودع.

---

## 💻 التطبيق المعماري (MVVM & Clean Code)

```dart
// ==========================================
// File: lib/features/tasks/presentation/viewmodels/task_list_viewmodel.dart
// Architecture Layer: Presentation (ViewModel)
// ==========================================

import 'package:flutter/foundation.dart';
import '../../data/models/task_model.dart';
import '../../data/repositories/task_repository_impl.dart';
import '../../../../core/enums/view_status.dart';

enum TaskFilter { all, active, completed }

class TaskListViewModel extends ChangeNotifier {
  final BaseTaskRepository _repository;

  TaskListViewModel(this._repository);

  ViewStatus _status = ViewStatus.initial;
  List<TaskModel> _tasks = [];
  TaskFilter _activeFilter = TaskFilter.all;
  String? _errorMessage;

  ViewStatus get status => _status;
  TaskFilter get activeFilter => _activeFilter;
  String? get errorMessage => _errorMessage;

  /// القائمة المصفاة التكيفية المعروضة للواجهة
  List<TaskModel> get filteredTasks {
    switch (_activeFilter) {
      case TaskFilter.active:
        return _tasks.where((t) => !t.isCompleted).toList();
      case TaskFilter.completed:
        return _tasks.where((t) => t.isCompleted).toList();
      case TaskFilter.all:
      default:
        return _tasks;
    }
  }

  /// جلب المهام الأولي
  Future<void> fetchTasks() async {
    _status = ViewStatus.loading;
    notifyListeners();

    try {
      _tasks = await _repository.getTasks();
      _status = _tasks.isEmpty ? ViewStatus.empty : ViewStatus.success;
    } catch (e) {
      _errorMessage = e.toString();
      _status = ViewStatus.failure;
    } finally {
      notifyListeners();
    }
  }

  /// إضافة مهمة جديدة
  Future<void> addNewTask(String title, String description) async {
    if (title.trim().isEmpty) return;

    final newTask = TaskModel(
      id: DateTime.now().millisecondsSinceEpoch.toString(),
      title: title,
      description: description,
    );

    await _repository.addTask(newTask);
    await fetchTasks(); // إنعاش القائمة بعد الإضافة
  }

  /// تغيير حالة إنجاز المهمة
  Future<void> toggleTask(String id) async {
    await _repository.toggleTaskCompletion(id);
    await fetchTasks();
  }

  /// تغيير الفلتر الحالي
  void setFilter(TaskFilter filter) {
    _activeFilter = filter;
    notifyListeners();
  }
}
```
