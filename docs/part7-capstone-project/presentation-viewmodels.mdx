# 7.3 طبقة العرض والـ ViewModel المشغلة لـ TaskFlow Pro

بناء الـ ViewModel الرئيسي الذي يدير إضافة، حذف، وتغيير حالة المهام وحساب نسبة الإنجاز المئوية.

##  أهداف الدرس (Learning Objectives)

---

## 1. حاسبة نسبة الإنجاز المئوية بالـ fold

### 📘 الشرح النظري
نحسب عدد المهام المكتملة مقسوماً على الإجمالي باستخدام دالة `fold` عالية الأداء.

### 💻 التطبيق العملي
```dart
class TaskListViewModel extends ChangeNotifier {
  final List<TaskModel> _tasks = [];
  List<TaskModel> get tasks => List.unmodifiable(_tasks);

  double get completionPercentage {
    if (_tasks.isEmpty) return 0.0;
    final completed = _tasks.fold(0, (sum, item) => item.isCompleted ? sum + 1 : sum);
    return (completed / _tasks.length) * 100.0;
  }
}
```

---

##  نصائح الأداء والتحسين (Performance Tips)

:::tip حماية القوائم بـ List.unmodifiable
يمنع التعديل المباشر على القوائم من خارج الـ ViewModel.
:::

##  أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. إتاحة القائمة الرئيسية التعديل المباشر بـ list.add() من الواجهة
List<Task> get tasks => _tasks; // 💥 يمكن استدعاء tasks.add() من الـ UI!

// ✅ الحل الصحيح
List<Task> get tasks => List.unmodifiable(_tasks);

```
