# 7.1 مشروع التطبيق التكاملي TaskFlow Pro (Setup)

في هذا الجزء النهائي، نقوم بتطبيق كافة مفاهيم الدورة لبناء تطبيق TaskFlow Pro المتكامل بالمعمارية النظيفة.

---

##  أهداف الدرس (Learning Objectives)

1. إعداد المجلدات والهيكل النهائي.
2. تهيئة GetIt و Provider للمشروع.
3. تجهيز ثيم التطبيق الداكن.

---

## 1. هيكل مشروع TaskFlow Pro النهائي

### 📘 الشرح النظري
نطبق هيكلة Feature-First الكاملة لعزل ميزة المهام `tasks` بالكامل.

### 💻 التطبيق العملي
```dart
/*
lib/
  ├── core/          # network, theme, utils
  └── features/
      └── tasks/     # data, domain, presentation
*/
```

---

##  نصائح الأداء والتحسين (Performance Tips)

البداية النظيفة بالهيكلة المحددة تضمن بناء مشروع متكامل بدون ديون تقنية.
:::
