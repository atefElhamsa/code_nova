## 1. موديل المهمة النظيف (TaskModel)

### 📘 الشرح النظري
نعرف TaskModel مع حقول ثنائية الحتمية ودالة copyWith.

### 💻 التطبيق العملي
```dart
class TaskModel {
  final String id;
  final String title;
  final bool isCompleted;

  const TaskModel({required this.id, required this.title, this.isCompleted = false});

  TaskModel copyWith({String? title, bool? isCompleted}) {
    return TaskModel(
      id: id,
      title: title ?? this.title,
      isCompleted: isCompleted ?? this.isCompleted,
    );
  }
}
```

---

##  نصائح الأداء والتحسين (Performance Tips)

:::tip كائنات ثنائية الحتمية Immutable Models
استخدام `copyWith` يمنع الطفرات غير المباشرة في الذاكرة.
:::
