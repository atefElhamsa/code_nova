## 1. شريط التصفية المقسم (SegmentedButton Filter)

### 📘 الشرح النظري
نستخدم `SegmentedButton` للتنقل المريح بين الحالات الثلاث (الكل، النشطة، المكتملة).

### 💻 التطبيق العملي
```dart
Widget buildFilterBar(TaskFilter current, ValueChanged<TaskFilter> onChanged) {
  return SegmentedButton<TaskFilter>(
    segments: const [
      ButtonSegment(value: TaskFilter.all, label: Text('الكل')),
      ButtonSegment(value: TaskFilter.active, label: Text('النشطة')),
      ButtonSegment(value: TaskFilter.completed, label: Text('المكتملة')),
    ],
    selected: {current},
    onSelectionChanged: (set) => onChanged(set.first),
  );
}
```
