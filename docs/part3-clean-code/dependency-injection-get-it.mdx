# 3.4 حقن التبعيات وحزمة get_it (Dependency Injection)

حزمة `get_it` هي مكتبة Service Locator الشهيرة لتزويد المشروع بالتبعيات وفصل إنشاء الكائنات عن استخدامها.

---

##  أهداف الدرس (Learning Objectives)

1. فهم مفهوم Service Locator.
2. التمييز بين registerLazySingleton و registerFactory.
3. ربط get_it مع Provider للـ ViewModels.

---

## 1. تسجيل التبعية الأحادية (registerLazySingleton)

### 📘 الشرح النظري
تُستخدم `registerLazySingleton` لتسجيل التبعيات التي نريد إنشاء نسخة واحدة منها فقط في الذاكرة طوال فترة تشغيل التطبيق (مثل Dio أو المستودعات).

### 💻 التطبيق العملي
```dart
import 'package:get_it/get_it.dart';

final GetIt sl = GetIt.instance;

void setupLocator() {
  // إنشاء نسخة واحدة فقط عند أول استدعاء
  sl.registerLazySingleton<UserRemoteDatasource>(
    () => UserRemoteDatasource(),
  );
}
```

---

## 2. تسجيل المصانع المتجددة (registerFactory)

### 📘 الشرح النظري
تُستخدم `registerFactory` لتسجيل التبعيات التي نريد إنشاء نسخة جديدة كلياً منها عند كل استدعاء (مثل الـ ViewModels للشاشات التفاعلية).

### 💻 التطبيق العملي
```dart
void setupViewModels() {
  // إنشاء نسخة جديدة عند كل شاشة
  sl.registerFactory<UserViewModel>(
    () => UserViewModel(sl<UserRepositoryImpl>()),
  );
}
```

---

##  نصائح الأداء والتحسين (Performance Tips)

:::tip التهيئة الكسولة للخدمات
استخدم `registerLazySingleton` لعدم استهلاك الرام في إنشاء خدمات حتى يحتاجها المستخدم فعلياً.
:::

---

##  أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. استدعاء get_it قبل إتمام التجميع setupLocator
void main() { runApp(MyApp()); setupLocator(); }

// ✅ الحل الصحيح
void main() { setupLocator(); runApp(MyApp()); }

```

---

##  أسئلة وأجوبة المقابلات (Interview Q&A)

<details>
<summary><strong>س1: ما الفرق بين registerSingleton و registerLazySingleton في get_it؟</strong></summary>

`registerSingleton` تنشئ الكائن فور التجميع، بينما `registerLazySingleton` تنشئ الكائن عند أول طلب فقط.

</details>

---

<ExerciseBox title="تمرين عملي - إعداد حاقن التبعيات 🏋️">

قم بتسجيل `AuthViewModel` كـ Factory و `AuthRepository` كـ LazySingleton في get_it.

</ExerciseBox>

<details>
<summary><strong>💡 اضغط هنا لرؤية الحل النموذجي المشروح بالتعليقات (Solution Code)</strong></summary>

```dart
final sl = GetIt.instance;
void setup() {
  sl.registerLazySingleton<AuthRepository>(() => AuthRepositoryImpl());
  sl.registerFactory<AuthViewModel>(() => AuthViewModel(sl()));
}
```

</details>

- `registerFactory` للنسخ المتجددة.
