# 3.3 هيكلة المجلدات حسب الميزات (Feature-First Folder Structure)

تنسيق المشروع بنمط Feature-First يضمن سهولة التوسع، حيث تُعزل كل ميزة (مثل الملاحظات، المصادقة) في مجلد خاص يضم طبقاتها الثلاث.

---

## 🎯 أهداف الدرس (Learning Objectives)

1. التمييز بين Feature-First و Layer-First.
2. تقسيم الميزة إلى data, domain, و presentation.
3. تخصيص مجلد core للعناصر العامة.

---

## 1. هيكل الميزة المفصولة (Feature Layers)

### 📘 الشرح النظري
تضم كل ميزة داخل `lib/features/feature_name/` الطبقات التالية: data (الموديلات والمستودعات)، domain (العقود والكيانات)، و presentation (الشاشات والـ ViewModels).

### 💻 التطبيق العملي
```dart
/*
lib/features/notes/
  ├── data/            # models & repositories impl
  ├── domain/          # entities & contracts
  └── presentation/    # views & viewmodels
*/
```

---

## 2. النواة المشتركة (Core Module)

### 📘 الشرح النظري
يُحتفظ بالخدمات التشاركية التي تخدم كافة الميزات (مثل Dio, AppTheme, Helpers) داخل مجلد `lib/core/`.

### 💻 التطبيق العملي
```dart
/*
lib/core/
  ├── network/         # dio_client.dart
  ├── theme/           # app_theme.dart
  └── utils/           # formatters.dart
*/
```

---

## ⚡ نصائح الأداء والتحسين (Performance Tips)

:::tip السهولة في الحذف والتعديل
نمط Feature-First يتيح لك حذف ميزة بالكامل بحذف مجلدها دون التأثير على باقي المشروع.
:::

---

## 🐛 أخطاء شائعة يجب تجنبها (Common Mistakes)

```dart
// ❌ 1. وضع كود مخصص لميزة واحدة داخل مجلد core العام
lib/core/widgets/note_card_widget.dart

// ✅ الحل الصحيح
lib/features/notes/presentation/widgets/note_card_widget.dart

```

<SummaryBox title="ملخص الدرس 📌">

- مجلد `core` مخصص للخدمات العامة المشتركة.
