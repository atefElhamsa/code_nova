# 🚀 CodeNova (Dart & Flutter + JavaScript Hub)

**CodeNova** هو منصة تعليمية تفاعلية شاملة مبنية باستخدام **Docusaurus 3** و **React**. تهدف المنصة إلى تقديم دورات برمجية احترافية بمعايير عالمية (مثل Dart & Flutter باستخدام MVVM و Clean Code، بالإضافة إلى مسار JavaScript).

تتميز المنصة بنظام مصادقة وتحكم في الوصول (Access Gate) متقدم مبني على **Supabase** لضمان حماية المحتوى وإدارة اشتراكات الطلاب بفعالية.

---

## ✨ المميزات الرئيسية (Key Features)

* **نظام إدارة صلاحيات متقدم (Access Gate):**
  * بوابة حماية مخصصة تمنع الوصول للمحتوى إلا بعد تسجيل الدخول وموافقة المشرف (Admin Approval).
  * ربط متكامل مع **Supabase** لإدارة المستخدمين (Authentication & Database).
  * إمكانية تسجيل الدخول عبر البريد الإلكتروني أو حساب Google.
  * نظام حالات للمستخدم (قيد الانتظار Pending، مصرح له Approved، أو محظور Blocked).
  * لوحة تحكم خاصة بالمسؤول (Admin Panel).
* **دورات احترافية متعددة:**
  * **مسار Dart & Flutter:** كورس شامل (33 درساً) يغطي الأساسيات، هيكلية Clean Code، إدارة الحالة (MVVM & Provider)، التكامل مع واجهات برمجة التطبيقات (API/Dio)، والاختبارات (Testing).
  * **مسار JavaScript:** قسم مخصص لتعلم لغة JS (منفصل بـ Plugin خاص في Docusaurus).
* **تصميم عصري وتجربة مستخدم ممتازة:**
  * واجهة مستخدم (UI) احترافية بالوضع الداكن (Dark Mode) الدائم.
  * دعم كامل لتخطيط الصفحات من اليمين لليسار (RTL) للمحتوى العربي، مع الحفاظ على تنسيق الأكواد (LTR).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **إطار العمل الأساسي:** [Docusaurus 3](https://docusaurus.io/) (مبني على React 18)
* **قاعدة البيانات والمصادقة:** [Supabase](https://supabase.com/)
* **لغة البرمجة:** TypeScript / JavaScript
* **إدارة الحزم:** npm
* **أدوات إضافية:** Prism (لتلوين الأكواد)، `@mdx-js/react`.

## 📂 هيكل المشروع (Project Structure)

* `docs/`: يحتوي على جميع ملفات ومقالات دورة Dart & Flutter (صيغة Markdown/MDX).
* `docs-js/`: يحتوي على ملفات ومقالات دورة JavaScript.
* `src/components/AccessGate.tsx`: مكون نظام الحماية والمصادقة المخصص للتحكم في وصول المستخدمين.
* `docusaurus.config.ts`: الإعدادات الرئيسية للمنصة (الروابط، القوائم، الإضافات، وإعدادات اللغات).
* `sidebars.ts` / `sidebars-js.ts`: ملفات تنظيم القوائم الجانبية وترتيب الدروس لكل دورة.
* `supabase/`: يحتوي على ملفات وإعدادات قاعدة بيانات Supabase.

## 🚀 التشغيل المباشر (Quick Start)

### 1. تثبيت الحزم (Install Dependencies)
تأكد من وجود Node.js (الإصدار 20 وما فوق الموصى به)، ثم قم بتشغيل:
```bash
npm install
```

### 2. تشغيل خادم التطوير المحلي (Local Dev Server)
```bash
npm run start
```
سيتم فتح الموقع تلقائياً على الرابط: `http://localhost:3000`

### 3. بناء نسخة الإنتاج (Production Build)
لتوليد الملفات النهائية الثابتة (Static Files) لرفعها على الاستضافة:
```bash
npm run build
```

## 🔐 نظام الصلاحيات للمستخدمين (User Flow)
1. **تسجيل حساب جديد:** يقوم الطالب بتسجيل حساب (بالإيميل أو عبر جوجل) وإدخال رقم الهاتف (للتواصل عبر واتساب).
2. **انتظار الموافقة (Pending):** يظهر للطالب شاشة تفيد بأن حسابه قيد المراجعة، مع توفير زر للتواصل المباشر عبر الواتساب لتسريع التفعيل.
3. **التفعيل (Approved):** يقوم المشرف بتغيير حالة المستخدم في قاعدة البيانات، ليتمكن بعدها من تصفح محتوى الدورات بالكامل.
4. **الحظر (Blocked):** في حال انتهاء الاشتراك أو حدوث أسباب أخرى، تظهر للمستخدم رسالة تفيد بإيقاف حسابه.
