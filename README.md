# دورة Dart & Flutter الشاملة | Docusaurus 3 Website

موقع تعليمي تفاعلي وبوابتك لتعلم لغة **Dart** وإطار عمل **Flutter** من الصفر وحتى الاحتراف باللغة العربية، وفق أعلى المعايير المعمارية العالمية (**MVVM Architecture + Clean Code**).

---

## 🚀 التشغيل المباشر (Quick Start)

### 1. تثبيت الحزم (Install Dependencies)
```bash
npm install
```

### 2. تشغيل سيرفر التطوير المحلي (Local Dev Server)
```bash
npm run start
```
سيفتح الموقع تلقائياً على العنوان: `http://localhost:3000`

### 3. بناء نسخة الإنتاج static (Production Build)
```bash
npm run build
```

## 🗺️ محتوى الكورس (33 درساً في 7 أجزاء)

1. **أسس لغة Dart (9 دروس)**: المتغيرات، Null Safety، التحكم بالتدفق، الدوال، المجموعات، OOP الأساسي والمتقدم، Generics، البرمجة غير التزامنية Futures & Streams.
2. **أساسيات Flutter (7 دروس)**: بيئة العمل، Widget Tree، ودجات التخطيط، ListView/GridView، التنقل بـ `go_router`، النماذج، السمات والوضع الداكن.
3. **مبادئ الكود النظيف Clean Code (4 دروس)**: قواعد التسمية، مبادئ SOLID و SRP، هيكلية Matures/Features-First (`core/`, `data/`, `presentation/`)، وحقن التبعيات بـ `get_it`.
4. **إدارة الحالة ونمط MVVM (5 دروس)**: تفكيك المعمارية، `ChangeNotifier` و `Provider`، دورة حياة الـ ViewModel، الربط المعماري (Wiring)، وتصميم حالات الواجهة (`Loading`, `Success`, `Error`).
5. **التكامل مع الخدمات الخلفية Backend (5 دروس)**: الاتصال بـ Dio & Interceptors، نمط المستودع Repository Pattern، معالجة الأخطاء بـ Failures، تسلسل JSON بـ `json_serializable`، والتخزين المحلي بـ `SharedPreferences`.
6. **الاختبارات Testing (درسان)**: كتابة Unit Tests للـ ViewModels والـ Repositories بـ `mocktail`، واختبارات الودجات Widget Testing.
7. **المشروع التطبيقي الشامل Capstone (5 دروس)**: تطبيق كامل لإدارة المهام TaskFlow Pro مبني صارماً بـ MVVM + Clean Code من التهيئة وحتى اختبارات الجودة والنشر.

## 🎨 المميزات والتصميم

- **تصميم ثنائي اللغة (Bilingual)**: شرح عربي أصيل أصيل بأسلوب مبسط وممتع مع المحافظة على المصطلحات التقنية الإنجليزية وكود Dart/Flutter باللغة الإنجليزية.
- **تخطيط RTL & LTR**: تخطيط عربي RTL للمقالات والشرح مع محاذاة LTR لجميع كتل الكود البرمجي (Code Blocks).
- **الوضع الداكن والفاتح**: دعم كامل للوضع الداكن (Dark Mode) بألوان Flutter الزرقاء (`#0175C2`).
